# 销售复盘核心规则

## 1. 核心定位

销售复盘不是会议纪要，也不是自我批评。它要把一次客户沟通转成下一次可用的判断和动作。

合格的销售复盘要做到：

1. 事实和推断分开。
2. 客户阶段判断清楚。
3. 卡点只抓主要卡点。
4. 句子级指出表达问题。
5. 下一步动作有人、事、时间。

## 2. 事实 / 推断分离

复盘先提取事实。

事实包括：

- 客户明确说过的话。
- 客户已经提供的信息。
- 顾问已经发出的材料。
- 已确认的下一步。

推断包括：

- 客户可能的真实顾虑。
- 客户是否还有兴趣。
- 客户家里是否有人影响决策。
- 顾问表达是否让客户有压力。

推断必须标明依据，不能写成确定事实。

## 3. 客户阶段

| 阶段 | 表现 | 下次重点 |
|---|---|---|
| 刚建立联系 | 只简单问一句，还没有背景 | 先接住，补最小信息 |
| 识别需求 | 愿意讲背景，但需求没收拢 | 问关键问题 |
| 比较方案 | 已经看方案或在比不同选择 | 做取舍说明 |
| 卡在异议 | 出现拖延、抗拒或顾虑 | 交给异议处理 |
| 接近成交 | 下一步动作明确，只差材料或确认 | 稳住节奏 |
| 成交后服务 | 已完成配置或进入服务 | 做服务显化和转介绍铺垫 |

## 4. 销售卡点

每次只抓 1 个主卡点，最多 2 个次卡点。

常见卡点：

- 客户不准：客户不是当前方案适合的人。
- 需求不清：没有问清客户真正想解决什么。
- 解释过多：顾问讲太满，客户没有参与感。
- 术语太多：客户听不懂。
- 推进太快：客户还没消化就被推动下一步。
- 异议没拆：把“再考虑”当成简单拒绝。
- 跟进不连续：会后没有明确动作和时间。

## 5. 沟通表达诊断

重点看 5 类问题：

- 追问太急。
- 结论太弱。
- 术语太多。
- 过度解释。
- 缺少动作引导。

句子级复盘用这个表：

| 原句 | 问题 | 更合适说法 |
|---|---|---|

不要为了好听把话术改得太完美，要保留真实微信或面谈口气。

## 6. 下一步动作

下一步动作必须具体。

格式：

```text
负责人 + 动作 + 材料 + 时间
```

示例：

```text
顾问明天中午前发一份保单整理清单，请客户先补现有保单目录，再约 20 分钟电话。
```

## 7. 可复用经验

每次复盘至少沉淀 1 条经验。

可复用经验可以是：

- 一个有效追问。
- 一个更稳的边界表达。
- 一个客户常见顾虑。
- 一个需要提前发送的材料。
- 一个不该再说的句子。

经验必须来自这次材料，不能泛泛写“下次多沟通”。
