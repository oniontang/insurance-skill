# 产品库条目模板

为每个主营产品复制一份下方条目模板，填写后保存到 `assets/product-library.md`（每行一个产品）。信息来自产品条款与公司培训口径，**不要凭印象填数字**，收益类信息留"以计划书为准"。

## 条目模板

```
### 【产品名称】

- 产品类型：增额终身寿 / 年金（教育金 / 养老金）/ 分红 / 万能 / 重疾 / 医疗 / 定期寿险
- 承保公司：
- 一句话定位：（客户视角，20 字内，如"把教育金按合同写死到孩子 18 岁"）
- 目标人群：（哪些客户最适合，尽量具体，如"30-45 岁、孩子 5-12 岁的中产家庭"）
- 不适合谁：（明确排除项，避免误推，如"5 年内要用这笔钱的客户"）
- 投保年龄 / 职业限制：
- 缴费方式与起售门槛：（趸交/3/5/10 年交，年缴最低多少）
- 核心卖点 TOP3：（每条一句话，对应客户的一个痛点）
- 讲解要点：（见 references/proposal.md 对应产品线，写本品独有的点）
- 关键规则：（减保限制、领取规则、犹豫期、健康告知要点等）
- 常见异议与应对：（本品特有的 1-2 条，通用异议见 references/scripts.md）
- 合规注意：（如"分红演示必须区分保证/非保证"）
- 计划书与条款获取方式：
```

## 示例条目（占位演示，请替换为真实产品）

### 【示例·XX 岁岁盈增额终身寿】

- 产品类型：增额终身寿
- 承保公司：（示例）XX 人寿
- 一句话定位：把长钱锁进合同，每年确定长大，急用钱能减保能贷款
- 目标人群：30-50 岁有 5 年以上闲钱、追求确定性的客户
- 不适合谁：3 年内有购房/结婚等大额支出计划的客户
- 投保年龄 / 职业限制：出生满 28 天 - 65 周岁；1-4 类职业
- 缴费方式与起售门槛：趸交 / 3 / 5 / 10 年交，年缴 1 万起
- 核心卖点 TOP3：
  1. 现金价值写进合同，每一年都确定可见
  2. 利率下行期锁利，今天投保就是未来利率的地板
  3. 支持减保取现与保单贷款，灵活应对应急
- 讲解要点：（本品独有）第 X 保单年度现金价值超已交保费（具体年份以计划书为准）
- 关键规则：减保每年限额以条款为准；犹豫期 15 天
- 常见异议与应对："收益不如基金"→ 用"这笔钱要的是确定不是进攻"重构（见 scripts.md 异议 1）
- 合规注意：不得承诺收益率，演示数字以计划书为准
- 计划书与条款获取方式：公司展业系统 / 请向上级索取
