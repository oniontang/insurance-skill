# 保单检视与整理

保单检视是理财险销售最强的二次切入场景：给老客户或陌生客户做免费检视，既建立专业信任，又自然暴露保障与储蓄缺口。

## 一、检视流程（五步）

1. **收集**：请客户列出全部保单（含家人、含线上互保/团险），提供保单首页照片或信息即可，不必完整合同。可使用 `assets/policy-review-report-template.md`。
2. **整理**：按"给谁保、保什么、保多久、保多少、交多少"五要素逐张拆解。
3. **诊断**：对照家庭责任识别问题（见下方诊断清单）。
4. **呈现**：用检视报告面对面讲解，先讲"已有的"给予肯定，再讲"缺的"提出建议。
5. **跟进**：给出优先级行动清单（先补什么、后补什么、不用动什么），约定下次检视时间（建议年度）。

## 二、逐张保单拆解要素

| 要素 | 关注点 |
|------|--------|
| 给谁保 | 投保人/被保人/受益人结构是否合理（豁免、传承定向） |
| 保什么 | 重疾/医疗/意外/定寿/年金/增额寿——类型是否与需求匹配 |
| 保多久 | 定期还是终身；理财险的缴费期与持有期 |
| 保多少 | 保额是否够（重疾 ≥ 年收入 3-5 倍；定寿 ≥ 负债 + 子女抚养成本） |
| 交多少 | 保费占家庭年结余比例是否超载（全家保费 ≤ 年结余 15-20%） |

## 三、诊断清单（按优先级）

**P0 立即风险**
- 家庭经济支柱无重疾/寿险保障
- 保单即将失效（宽限期临近）或缴费困难
- 受益人未指定或已不符合意愿（如仍为前配偶）

**P1 明显缺口**
- 保额不足：重疾保额低于年收入 3 倍、定寿未覆盖房贷
- 有理财险无保障险：地基没打先盖楼
- 孩子齐全、大人裸奔（最常见误区）

**P2 结构优化**
- 理财险占比过高、流动性紧张
- 多张小额保单分散、管理混乱
- 年金领取时点与实际用钱时点错配

**P3 锦上添花**
- 利率下行下的锁利加保空间
- 传承安排（指定受益人、比例分配）

## 四、检视报告呈现话术

开场定调："今天不推任何产品，就做一件事——把您家的保单理清楚。先看咱们已有的保障，其实已经覆盖了 X，做得挺好；再看两个建议关注的地方，您听完自己判断。"

讲缺口时："这里不是说您买错了，而是这几年家庭情况变了——房贷多了、二宝出生了，保单也要跟着家庭一起长大。"

**严禁**：贬低客户已购保单或已购渠道；对客户已购产品的问题如实客观陈述即可。

## 五、产出标准

用户请求做保单检视时：

1. 先确认已收集的保单信息是否完整，缺什么列清单让用户补
2. 按 `assets/policy-review-report-template.md` 生成完整检视报告
3. 报告后附 3 条以内的优先级行动建议
4. 涉及具体产品利益测算时留占位符并注明以计划书为准
