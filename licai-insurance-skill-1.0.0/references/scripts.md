# 关键节点话术库

话术提供"结构 + 示例"。使用时先判断客群（年轻上班族/中产家庭/中高净值），把示例改写成贴合客户场景的语言。所有涉及收益的表述必须遵守 SKILL.md 合规红线。

## 一、开场破冰

**结构**：寒暄定调 → 说明来意（利他视角）→ 抛出轻问题。

- 中产家庭示例："姐，最近好多客户都在问我同一件事——存款利息一路往下走，手里这钱到底该放哪。我倒不是急着让您买什么，就想问问您家里现在这钱是怎么安排的？"
- 中高净值示例："X 总，今天来不是推销产品的。最近预定利率又调整了，我整理了一份对高净值客户资产配置的影响分析，想听听您对现在这种低利率环境的看法。"
- 年轻客户示例："哥们儿，你现在每个月工资到账，是花剩下才存，还是先存再花？"

## 二、产品引入（从需求到产品的桥）

**结构**：确认需求 → 给出三类资金去向框架 → 引导定位。

话术框架："您这笔钱按用途其实就三种放法：**要花的钱**（灵活取用，放活期/货基）、**保命的钱**（应对突发，靠保障型保险）、**确定要花的钱**（教育、养老，几年内不能亏也不能不动）——您刚才说的教育金，就属于第三种。这种钱最好的工具之一就是年金/增额终身寿，因为它把'利率'和'纪律'都写进了合同。"

## 三、常见异议处理（先认同 → 重构 → 给证据 → 收口）

**1. "收益太低了，还不如买基金/炒股"**
- 认同："对，论进攻性保险肯定比不过权益类。"
- 重构："但咱们刚才聊的这笔钱，是孩子 X 年后一定要花的，它的要求不是高收益，是**一分都不能少**。"
- 给证据："您看这本来就是组合：进攻的钱您继续投基金，这笔钱用保险锁底。账户里有攻有守，您睡得着觉。"
- 收口："要不这样，您拿一小部分先做个底仓试试？"

**2. "钱放进去十几年取不出来，太不灵活了"**
- 认同："您这个顾虑特别对，保险确实不适合放短期要用的钱。"
- 重构："反过来讲，正因为取出来'麻烦'，它才帮您把钱留住了——您想想之前存的钱，是不是总有各种理由被花掉？"
- 给证据："而且真急用也有办法：可以减保取一部分，也可以保单贷款，一般能贷现金价值的 80% 左右，保单继续有效。"（具体以条款为准）
- 收口："所以我们只放长钱、闲钱，短钱咱一分不动它。"

**3. "我再考虑考虑 / 跟家人商量一下"**
- 认同："应该的，这么重要的决定是要跟家人商量。"
- 重构："那我帮您把方案浓缩成一页纸，您回家讲给家人听也方便。另外我想确认一下：您本人对方案本身还有没有疑虑？还是纯粹需要时间？"
- 给证据：给出一页纸方案摘要 + 约定回访时间。
- 收口："咱们约周四晚上，您和家人一起，我把疑问当场解答清楚，好不好？"

**4. "我在银行也看了类似的，你们有什么不一样"**
- 合规提示：不得贬低同业与银行渠道。
- 应对："银行渠道也很好，产品形态确实有些相似。区别主要在服务上：我能帮您做的是**长期的、动态的**规划——今年看教育金，五年后看养老，保单检视、理赔协助都是我全程跟。您买的不只是单张保单，是一个一直在的人。"

**5. "利率一直在降，是不是再等等更好的产品"**
- 重构："您说得对，正因为利率一直降，等通常是更亏的——您等到的不是更好的产品，而是更低的利率。"
- 给证据："现在这份保单的利益是写进合同的，从签单那天起就锁定终身。今天锁定，就是未来十年的最高点。"（合规表述，不承诺未来产品变化）

## 四、促成

**信号识别**：客户开始问细节（缴费期、领取方式）、问"如果中途要用钱"、让家人参与讨论、反复看方案——都是促成信号。

**二选一法**："您看缴费是选 5 年还是 10 年？以您的现金流，10 年每年压力小一些，5 年总利益更好一点，您更倾向哪个？"

**门槛降低法**："咱们先按您没压力的额度起步，比如年交 X 万，先把这个底仓建起来，以后宽裕了再加。"

**稀缺事实法**（合规版）："这个预定利率的产品窗口期是监管定的，如果这批停售，下一批的利益就按新利率算。咱们不用抢，但真没必要等。"

## 五、转介绍

**时机**：成交后服务节点（回访、理赔协助、保单检视）是最佳时机，不在签单当场逼单。

**话术结构**：感谢 + 服务承诺 + 轻请求。
- "哥，接下来您的保全、理赔，有任何事直接找我，我全程负责。另外有个小忙想请您帮——您身边有没有一两个朋友，也正为孩子的教育金或者养老规划发愁的？您帮我牵个线，我肯定像服务您一样服务他，绝不硬推。"

## 六、话术产出标准

为用户生成话术时，按以下格式输出：

1. 适用客群与场景
2. 话术结构（分步骤）
3. 完整示例（口语化，可直接念）
4. 合规检查提醒（若涉及收益表述）
5. 使用注意事项（什么时候说、什么时候停）
