# 客户关怀与祝福

成交靠专业，续期与转介绍靠关心。本模块覆盖生日/节日祝福、日常关心、成交后祝福，目标是让客户记住"这个人心里有我"，而不是"这个人总想卖我东西"。

## 一、关怀的基本原则

1. **无推销原则**：关怀信息中禁止出现产品名、收益、促单话术。关怀就是关怀，夹带推销会同时毁掉信任和后续成交机会。
2. **个性化优先于华丽**：一句提到客户具体细节的祝福（孩子名字、上次的旅行、刚交房的房子）胜过十句辞藻华丽的模板。
3. **分层控频**：接触频率遵循 `ops.md` 客户分层（A 层每月 1 次、B 层每季度 1-2 次、C/D 层季度或半年 1 次），生日/节日触达计入总频次，不叠加轰炸。
4. **渠道匹配**：微信文字/语音适用于大多数场景；A 层大客户生日可加手写卡片或快递小礼物（金额注意公司合规与税务口径）；避免深夜、工作时间密集发送。

## 二、全年关怀日历

按"固定节日 + 个性化日期 + 时机事件"三类管理，建议用户维护在自己客户表格中：

| 类型 | 触点 | 说明 |
|------|------|------|
| 个性化日期 | 客户生日、客户结婚纪念日、子女生日 | 最高优先级，提前 1-3 天准备好当天发送 |
| 固定节日 | 春节、元宵、端午、中秋、元旦、妇女节、儿童节、重阳节 | 挑选与客户身份匹配的节日，不必每个都发 |
| 时机事件 | 子女高考/开学、乔迁、升职、公司上市、康复出院 | 从聊天中捕捉，事件关怀比节日关怀更显用心 |

节日取舍原则：与客户身份强相关的才发（如客户是妈妈→母亲节/儿童节借她孩子；企业主→不必发妇女节）。群发感是关怀的头号杀手，一条群发不如不发。

## 三、祝福话术结构

**结构**：称呼 + 具体化钩子 + 真诚祝福 + 轻收尾（不推销）。

- **称呼**：贴合日常称呼习惯（姐/哥/X 总），不用"尊敬的客户"。
- **具体化钩子**：一个只属于这个客户的细节（"年年都记得您说过女儿属兔""您上次说体检查出脂肪肝在跑步"）。
- **真诚祝福**：落在客户在意的事情上（健康、孩子、事业），不落在钱上。
- **轻收尾**：以"不必回复"的姿态结束，降低回复压力；仅在 A 层特殊节点可附轻服务提醒（如"保单下月缴费，到时我提醒您"）。

### 生日示例

- 中产家庭："芳姐，生日快乐🎂 记得您说过这是'奔四最后一个生日'，要开开心心地过。孩子们都大了，往后每年这天都是您最该对自己好的日子。祝您身体健康，笑口常开，不用回我，替我多吃块蛋糕～"
- 中高净值："X 总，生日快乐。这两年看您把公司交班的事安排得越来越顺，家庭事业都稳。祝新的一岁身体康健、诸事从容。改天茶叙不聊业务，就当给您贺寿。"
- 年轻客户："小陈生日快乐呀🎂 又长大一岁！记得你说的目标——今年把'先存再花'坚持下来，年底验收哈。祝新的一岁搞钱顺利、快乐加倍！"

### 节日示例

- 中秋："王哥，中秋快乐。月饼少吃点，您那血糖刚降下来😄 家人团圆最重要，祝全家安康喜乐。"
- 春节："李姐，新年好！这一年多谢您的信任和照顾，看着孩子基金定投也走上正轨，特别为您高兴。祝您全家新年顺遂、平安喜乐。来年有任何需要，随时找我。"

### 时机事件示例

- 子女高考放榜："赵哥，听说孩子录取了，真心为您高兴！十二年陪读不容易，这一刻都值了。孩子开学前的行前准备有什么要参考的，随时喊我。"
- 康复出院："钱姐，听说您出院了，太好了！医生说的恢复期注意事项您一定按医嘱来，别逞强。好好休养，不着急回消息。"

## 四、成交后的祝福与关怀节点

成交不是句号，是服务关系的开始。祝福与关怀按以下节奏（与 ops.md 90 天节奏配合）：

1. **成交当天**：祝福 + 感谢 + 责任承诺。示例："张哥，恭喜咱们今天把这事儿定下来了！感谢您的信任，这份保单从现在起就是我的事——回执、回访、缴费提醒、以后任何保全理赔，您只管找我。今晚回家跟嫂子报个喜，祝咱们合作愉快，也祝您和家人越来越安心。"
2. **犹豫期回访（第 7 天）**：如实确认保单信息与犹豫期权利，语气是"为您把关"而非"怕您退"。
3. **首期缴费前**：提前 3 天温馨提醒，确认扣款账户余额，避免失效。
4. **客户生日（成交后首个）**：首次生日关怀格外用心，这是成交后第一个"非业务触点"，决定客户把您归为"销售"还是"朋友"。
5. **重大节日**：按分层频率执行，成交后第一个春节建议 A/B 层全部覆盖。

## 五、合规与分寸红线

1. 祝福内容不得出现产品推荐、收益演示、停售逼单信息。
2. 不得使用"感恩回馈老客户，产品即将停售"等借节日包装的营销话术。
3. 礼物往来注意金额合规，遵循所属公司礼品与反商业贿赂规定。
4. 客户明确表示不愿被打扰的，立即移出关怀名单并记录偏好。
5. 涉及客户健康信息（如术后关怀）只表达关心，不复述病情细节、不提其他客户病情。

## 六、关怀产出标准

为用户生成关怀内容时，按以下格式输出：

1. **触点与时机**（哪个客户、哪个日期、什么渠道）
2. **2-3 版文案**（口语化、可直发，标注适用场景差异）
3. **个性化钩子提示**（提醒用户替换成客户真实细节的位置）
4. **注意事项**（频次/合规/该客户特殊偏好）
