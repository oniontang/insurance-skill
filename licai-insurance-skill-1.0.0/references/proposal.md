# 方案设计与产品讲解

## 一、总原则：先讲"为什么是这个工具"，再讲"产品"

讲解顺序固定为：**需求回放 → 工具逻辑 → 产品形态 → 数字演示 → 适配确认**。跳过前两步直接报产品，是新手最常见的失败原因。

所有演示数字使用占位符（如【第 10 保单年度末现金价值：以官方计划书为准】），不虚构产品数据；正式数字一律以保险公司计划书为准。

## 二、各产品线讲解逻辑

### 增额终身寿险（主打"确定性"）

**一句话定位**：把一笔钱按写进合同的确定节奏长大，锁定终身，灵活可减保。

**讲解要点**：
1. 现金价值白纸黑字写进合同，每一年的价值确定可见
2. 利率下行周期中"锁利"价值：今天的数字就是未来的地板
3. 灵活性：减保取现（按条款规则）、保单贷款应急
4. 适配客群：有长期闲钱、追求确定、可能有大额支出安排（教育/置换/备用金）的客户

### 年金险（主打"现金流规划"）

**一句话定位**：把存量变成确定领取的终身现金流，专款专用于教育或养老。

**讲解要点**：
1. 与生命等长的现金流——"活多久领多久"，解决长寿风险
2. 教育金：领取时点匹配高中/大学/深造节点；养老金：匹配退休后收入缺口
3. 强制纪律：这笔钱"生不出孩子也动不了"，杜绝挪用
4. 适配客群：目标明确（教育/养老）、怕自己管不住钱的客户

### 分红险 / 万能险（主打"保底 + 浮动"）

**讲解要点（合规敏感，必须区分保证与非保证）**：
1. 先讲保证部分：保底利率/保证利益，写进合同
2. 再讲浮动部分：分红取决于保险公司分红账户实际经营水平，**是不确定的**，历史上不作为未来承诺
3. 讲清机制：分红来源（利差、死差、费差）、红利实现率概念
4. 万能账户：保底结算利率 + 实际结算利率（每月公布，仅对超过部分不确定）
5. 适配客群：能接受"保底之上博更高"、理解浮动收益的客户；对纯确定性要求极高的客户慎推

### 重疾险（保障型，组合销售的压舱石）

**讲解要点**：
1. 功能不是"投资"而是"收入损失补偿"——罹患重疾后 3-5 年收入中断的缺口
2. 讲"保额倒推法"：年收入 × 3-5 年 + 治疗自费部分 ≈ 建议保额
3. 健康告知如实义务必须讲清，双向保护客户
4. 适配客群：所有客群的家庭经济支柱，建议在理财配置之前补足

### 组合销售（保障 + 理财）

**标准逻辑：先保障，后理财；先保额，后保费。**

组合叙事："咱们分两步走：第一步，把家庭保障的底建起来（重疾+医疗+定期寿险），确保任何风险都不击穿家庭财务；第二步，在这个底上做长期储蓄规划（年金/增额寿）。地基牢了，楼才敢盖高。"

预算分配参考（按客户接受度调整）：年结余中先安排保费预算不超过 10-15%，其中保障型占大头，理财型量力而行。

## 三、收益演示方法（不讲 IRR 术语，讲三种对比）

**1. 确定性对比**：同一笔钱，"存银行按当前利率并假设逐年下调" vs "保险合同锁定值"——两条曲线放一张图（数字以计划书为准，利率假设需注明为假设）。

**2. 时间价值故事化**："第 5 年，账户里是 X；第 10 年翻到 Y；到孩子 22 岁那年，是 Z——正好覆盖四年大学加留学准备金。"把现金价值表翻译成客户人生事件。

**3. 缺口倒推**：目标金额（如教育金 80 万）→ 倒推每年需存多少、存几年 → 给出 2-3 档方案（保守/标准/充裕）让客户选，而不是给单一答案。

**严禁**：与非保险产品做确定性收益对比、使用"复利 X%"等暗示承诺的表述。

## 四、方案产出标准

为用户生成方案讲解材料时，输出结构：

1. **需求回放**（3 行以内，用客户原话）
2. **规划目标**（量化的缺口或目标）
3. **推荐方案结构**（产品形态 + 缴费安排，不含具体产品费率）
4. **讲解脚本**（按上面五步顺序的口语化讲稿）
5. **三档方案对比表**（预算档位）
6. **合规提示**（本方案涉及的演示规则）
