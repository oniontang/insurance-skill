# 客户经营与复盘

单次成交靠话术，长期业绩靠经营。本模块覆盖成交后的客户分层经营、跟进节奏、加保与转介绍、以及未成交复盘。

## 一、客户分层经营

按两个维度分层：**当前价值**（已交保费/潜在加保空间）与 **活跃度**（互动频率）。

| 层级 | 定义 | 经营策略 | 接触频率 |
|------|------|---------|---------|
| A 层 | 已成交大单 + 高转介绍潜力 | 专属服务：生日/节日定制化关怀、年度检视、家庭日沟通 | 每月至少 1 次 |
| B 层 | 已成交小额 + 需求未配齐 | 检视切入、分阶段补齐方案、内容养熟 | 每季度 1-2 次 |
| C 层 | 未成交待激活 | 价值内容触达（利率变化、政策解读），等窗口期 | 每季度 1 次轻触达 |
| D 层 | 沉默客户 | 批量运营：朋友圈、节日群发、年度激活活动 | 半年 1 次 |

## 二、跟进节奏（成交后 90 天黄金期）

1. **第 1 天**：感谢 + 确认保单信息与缴费方式
2. **第 7 天**：回访确认（犹豫期提醒，如实沟通犹豫期权利）
3. **第 30 天**：服务交付——讲解保全功能（地址变更、受益人修改等），建立"有事找我"心智
4. **第 60 天**：价值触达——发送与其规划相关的内容（教育金进展、利率资讯）
5. **第 90 天**：保单检视邀约 + 转介绍窗口

## 三、朋友圈与内容经营（合规版）

- **发什么**：展业日常（真实感）、客户服务故事（脱敏）、政策/利率解读（客观转述）、理赔协助案例（脱敏授权）
- **怎么发**：生活内容 : 专业内容 ≈ 3:2，避免刷屏式产品广告
- **合规**：不夸大收益、不制造停售焦虑恐慌、不使用"最后 X 小时"式逼单文案；停售信息如实客观陈述即可

## 四、未成交复盘法（每单必复盘）

按四步复盘，输出到用户的工作记录：

1. **事实层**：客户类型、接触过程、卡在哪一步（需求挖掘/方案/异议/促成）
2. **原因层**：是信息没摸清（KYC 不足）、价值没讲透（演示不达意）、还是时机未到（预算/决策链）
3. **经验层**：哪句话让客户眼神变了、哪个问题问对了、哪个环节话太多
4. **行动层**：下次跟进的具体动作 + 时间点 + 触发理由；放入 C 层持续经营而非放弃

复盘产出口径："没成交 ≠ 失败，是经营周期中的一个节点。约 60% 的大单来自首次接触后 6 个月以上的跟进。"（经验参考值，非统计数据）

## 五、加保逻辑

触发时机（满足其一即可发起）：
- 客户家庭结构变化：结婚、生子、置业、收入跃升
- 外部窗口：利率下调周期、政策调整
- 保单年度检视时发现缺口
- 客户主动咨询新的资金安排

加保话术结构：**回顾（当年方案解决什么）→ 变化（家庭/利率变了）→ 建议（补多少、怎么补）→ 选择权交还客户**。

## 六、产出标准

用户请求经营支持时：

1. 明确客户所处层级与当前阶段（90 天节奏中的哪一步）
2. 给出具体可执行的下一步动作 + 话术
3. 复盘类请求按四步法输出结构化复盘
4. 所有触达内容做合规自查
