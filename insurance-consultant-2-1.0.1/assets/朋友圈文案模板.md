```

孩子还小，贷款还没还完，配偶一个人扛着。

只是清明节，是个很好的时机，认真想一下：

我走了，家里还好吗？

我不推贵的，只推对的。

```

```

这是好事，说明国家在努力。

但我也要说一句大实话：
医保报的是目录内的，
进口药、特效药、靶向药，
医保报不了。

生一场大病，差距有多大？
几十万，甚至上百万。

你有医保，也要有商业保险——
```
