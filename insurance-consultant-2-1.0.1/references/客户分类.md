# 客户分类框架

> 按家庭结构+经济状况+风险偏好进行分类，制定差异化服务策略

---

## 一、客户分类维度

### 按家庭结构分类

| 类型 | 特征 | 核心需求 | 推荐产品优先级 |
|------|------|---------|--------------|
| **单身期** | 25-35岁，未婚/恋爱中 | 自我保障 + 财富积累 | 消费型重疾 → 百万医疗 → 意外险 → 年金险 |
| **新婚期** | 30-35岁，刚结婚无孩 | 双方保障 + 家庭责任建立 | 重疾 + 医疗 + 定期寿险 + 意外险 |
| **家庭形成期** | 30-40岁，有1个孩子 | 子女保障 + 父母核心保障 | 重疾 + 医疗 + 定寿 + 教育金 |
| **多子女家庭** | 35-50岁，2-3个孩子 | 教育金规划 + 父母核心保障 + 家庭总保费合理分配 | 定寿 + 重疾 + 教育金 + 家庭总保费控制 |
| **中年稳定期** | 40-55岁，子女成人 | 养老规划 + 资产传承 | 年金险 + 增额寿 + 高额寿险 + 财富传承 |
| **退休期** | 55岁以上 | 医疗补充 + 养老年金 + 护理保障 | 医疗险 + 防癌险 + 护理险 + 养老年金 |

---

### 按经济状况分类

| 类型 | 家庭年收入 | 风险偏好 | 建议策略 |
|------|----------|---------|---------|
| **基础型** | <15万 | 保守 | 先覆盖核心风险（医疗+意外），不追求全面 |
| **标准型** | 15-40万 | 稳健 | 保障+积累并重，重疾+医疗+定寿+基础年金 |
| **品质型** | 40-100万 | 均衡 | 全险种覆盖，品质医疗 + 养老规划 + 资产配置 |
| **富裕型** | 100万+ | 进取 | 高额保障 + 财富传承 + 税务筹划 + 全球医疗 |

---

### 按风险偏好分类

| 类型 | 典型表现 | 沟通策略 |
|------|---------|---------|
| **保守型** | "我不需要" | 从恐惧入手，找到经济安全感缺口 |
| **稳健型** | "你看着办" | 主动给方案，适度引导决策 |
| **进取型** | "我有更好的投资" | 用确定性话术，年金险 vs 其他资产 |
| **冲动型** | "这个好，买了" | 帮他冷静，分析真实需求后再决定 |
| **拖延型** | "再等等" | 不催，但设时间节点，强调年龄/健康因素 |

## 二、高频客户画像详解

### 画像1：30岁科技行业程序员

**特征**：
- 未婚或新婚，收入较高（月入2-5万）
- 工作强度大，加班多，饮食不规律
- 自认为年轻不需要保险
- 有投资理财习惯（股票/基金）

**痛点挖掘**：
> "你们程序员收入高，但也高强度。万一生了大病，不只是治疗费，还有收入中断。你账户里的钱够撑多久？"

**推荐方案**：
- 重疾险（保额=3-5年年收入）
- 百万医疗险
- 意外险
- （如有房贷）定期寿险

---

### 画像2：35岁有娃的新中产

**特征**：
- 已婚有1-2个孩子
- 房贷100-300万
- 家庭收入主力，双薪家庭
- 开始考虑子女教育和养老

**痛点挖掘**：
> "你现在是家庭的印钞机。万一这台印钞机停了，孩子的教育、房贷、家里日常开销，谁来出？定期寿险就是给你家这台印钞机买的一个备份。"

**推荐方案**：
- 定期寿险（覆盖房贷余额）
- 夫妻双方重疾险
- 百万医疗险
- 子女教育金（年金险）
- 家庭综合意外险

---

### 画像3：45岁企业主

**特征**：
- 家庭净资产较高
- 事业繁忙，压力大
- 资产配置多元（房产/股票/企业）
- 对传承有需求

**痛点挖掘**：
> "你现在最怕的是什么？资产传承损耗？还是企业经营风险影响到家庭？寿险是确定性最高的传承工具，不受债务和税务影响。"

**推荐方案**：
- 高额终身寿险（传承功能）
- 年金险（养老+现金流）
- 企业团险（员工福利）
- 高端医疗险

---

### 画像4：55岁临近退休

**特征**：
- 子女已成年，房贷接近还清
- 退休金规划意识强
- 身体健康状况开始出现信号
- 对医疗险投保年龄敏感

**痛点挖掘**：
> "现在投保医疗险，核保更严，保费也更高。但医疗险是晚年在医院里最大的底气——进口药、特效药，有它才敢用。"

**推荐方案**：
- 百万医疗险（尽快投保）
- 防癌险（健康告知宽松）
- 护理险（长护险趋势提前布局）
- 养老年金险（补充退休金）

## 三、客户沟通优先级

### 优先级排序逻辑

| 优先级 | 客户类型 | 理由 |
|--------|---------|------|
| ⭐⭐⭐ | 有娃 + 有房贷 + 家庭支柱 | 保障缺口最大，需求最刚 |
| ⭐⭐⭐ | 高净值客户 | 单笔保费高，服务价值大 |
| ⭐⭐ | 已有一份保单的老客户 | 加保比新开发容易 |
| ⭐⭐ | 年轻单身（30岁以下）| 保费低但健康状况好，可长期服务 |
| ⭐ | 中老年首次接触 | 健康告知复杂，需谨慎 |

## 四、客户需求四问（标准化开场）

每次接触新客户，执行以下四问：

1. **预算**：你每年能承受多少保费？（建议不超过年收入的15-20%）
2. **担忧**：你最大的担忧是什么？（生病/意外/养老/传承）
3. **现有保障**：你目前有哪些保险？（了解已有覆盖，避免重复）
4. **家庭责任**：你家里有哪些固定支出？（房贷/子女教育/老人赡养）

> 问完这四个问题，80%的客户需求已经清晰了。
