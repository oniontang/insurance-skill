## 一、泛保险生活化选题池（按场景 / 人群 / 险种）

### A. 人生阶段 / 生活场景
- 刚当妈：为什么第一时间给孩子买医疗险（场景型）
- 租房青年：最低预算搞定意外险（身份型）
- 房贷族：背着房贷，最该先保谁（痛点型）
- 备孕 / 新手父母：少儿险怎么不花冤枉钱
- 父母养老：爸妈的保险，50岁后还能买什么
- 换工作 / 自由职业：社保断了保障怎么补
- 体检异常：结节 / 三高还能买保险吗（蓝海·谨慎措辞）
- 装修 / 出行 / 旅行：短期险怎么买最省

### B. 险种科普（对比拆解型，最稳爆款骨架）
- 座位险 vs 驾乘险：差几十万的真相（已验证 · 参考案例拆解见 content-framework 0.7）
- 重疾险 vs 医疗险：90%的人搞反的关系
- 定期寿险：顶梁柱的"留爱不留债"
- 百万医疗：免赔额 / 续保 / 特效药三大坑
- 年金 / 养老：现在存和以后买差多少
- 意外险：不保猝死的真相 + 3 个误区

### B+. 政策/法规/分级攻略（C11 · S41 笔记本手账长图首选 🎯）
- **保险分级制度正式落地**：产品5级+销售4级+客户匹配（来自公众号大号实战参考）
- **「适当性管理」新规解读**：对你买保险有什么影响？
- **重疾定义修订前后对比**：哪些病更容易/更难赔了
- **理赔规则最新变化**：2026年理赔要注意的X个变化
- **保险销售行为管理办法**：怎么判断你的代理人靠不靠谱
- **医保目录调整 + 商保衔接**：哪些药社保不报但商保能报

### C. 观念唤醒（情绪型封面）
- 你给车买全险，给自己呢？
- 如果明天不在了，家人找得到保单吗？
- 先保孩子还是先保大人？（反常识）
- 保险不是消费，是未雨绸缪的担当

## 三、小红书爆款复刻方向（按种草三板斧，见 content-framework 0.1–0.3）

- **对比拆解型**（最稳）：X vs Y 差在哪 → 座位险/驾乘险、重疾/医疗、大公司/互联网
- **避坑清单型**：买前必看 N 件事、N 个误区 → 高收藏
- **真实理赔故事型**：脱敏案例 + 温度 → 高信任高转化
- **分人群方案型**：宝妈 / 房贷族 / 新手司机各一套 → 高代入
- **数字冲击型**：90%人买错、一年省2000 → 高好奇
- **反常识型**：你以为对其实错 → 高点击
