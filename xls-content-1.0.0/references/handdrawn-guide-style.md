# 小绿书后端手绘指引图风格系统

> 封面负责"情绪勾人"，后端手绘图负责"专业留住人+让人收藏"。
> 手绘风 = 亲切、不说教、像朋友在纸上给你画重点，降低保险的距离感。
> 用途：把专业指导（顺序/对比/流程/清单）画成一眼看懂的手绘图。

---

## 一、手绘风视觉基因

| 元素 | 做法 |
|------|------|
| **纸张底** | 米黄/浅牛皮纸色（#f6f0e2 / #faf6ea），可加极淡网格或纸纹 |
| **字体** | 手写感字体（中文可用"手写体/圆体"，标题略歪、有温度）；正文用清晰圆体保证可读 |
| **线条** | 手绘感边框（不规则、略抖、圆角）、马克笔下划线、随手圈画 |
| **图标** | 简笔画风（小人/房子/心/盾牌/箭头），线条粗细不均，非标准 icon |
| **重点标记** | 马克笔高亮块（黄/绿半透）、红笔圈重点、★标注 |
| **配色** | 纸底 + 墨黑手写字 + 2 种马克笔色（暖黄#f2c65c / 墨绿#5a8a6f）+ 少量红笔#d8674f |

**核心原则**：像真人手绘草稿，有"呼吸感"和不完美感，**忌**规整死板的 PPT 感。

---

## 二、四种手绘指引图范式

### 范式 A · 步骤流程图（Steps）
- **用途**：把"该怎么做"分步骤画出来。
- **构图**：竖向 1-2-3 步骤，每步一个手绘编号圆 + 简笔图标 + 一句话，箭头串联。
- **示例**：家庭保单配置顺序（先大人→再小孩→先保障→后理财）。

### 范式 B · 对比图（VS）
- **用途**：错做法 vs 对做法、有 vs 无。
- **构图**：左右分栏，左边 ✗（红笔叉/灰暗），右边 ✓（绿勾/高亮），中间画一道手绘分割线。
- **示例**：「买错顺序 ✗ vs 买对顺序 ✓」。

### 范式 C · 清单勾选图（Checklist）
- **用途**：可收藏的行动清单。
- **构图**：手绘方框 □ + 勾选 ✓ + 每条一句话，重点词马克笔高亮。
- **示例**：「投保前自检 5 问」。

### 范式 D · 关系/结构图（Map）
- **用途**：讲清概念之间的关系（如险种拼图、家庭保障网）。
- **构图**：中心一个核心 + 手绘线条辐射到几个要素，像思维导图草稿。
- **示例**：「一个家庭的保障网：4 张保单各管什么」。

## 三、手绘图排版规范
- 每张图**只讲一个点**，信息 ≤5 条，宁少勿满。
- 标题手写体略大、可带下划波浪线；正文圆体保证清晰。
- 重点词用马克笔高亮（一张图 ≤3 处），红笔圈画 ≤1 处。
- 图标简笔化，别用写实/复杂图形。
- 尺寸：正文手绘图 1080×1350（3:4）或 1080×1080（1:1），与封面统一竖版。

## 四、技术实现（HTML+CSS+Playwright）
- 纸底：`background:#f6f0e2` + 可选极淡 `repeating-linear-gradient` 网格。
- 手写字体：优先系统手写体；无则用圆体 + `letter-spacing` 微调 + 轻微 `transform:rotate(-1deg)` 制造手写感。
- 手绘边框：`border` + `border-radius` 不规则值（如 `225px 15px 225px 15px/15px 225px 15px 225px`）模拟手绘框。
- 马克笔高亮：`background:linear-gradient(transparent 55%, rgba(242,198,92,0.6) 55%)` 压在文字下。
- 圈画：SVG 手绘椭圆 `<ellipse>` + `stroke-dasharray` 或不规则 path。
- 简笔图标：内联 SVG path（粗细不均线条）。
- 渲染同 `xls_image_builder.py` 的 render()，device_scale_factor=2。
