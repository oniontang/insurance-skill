# 小绿书视觉风格归档库（Style Archive）

> **定位**：这是小绿书 skill 的「风格地基」。把所有可用风格先归档成规范，
> 后续写内容时**只选风格 + 填文字/调排版**，不再为「这个图该什么风格」反复讨论。
> 每条风格 = 一个可复用的视觉模板家族，统一管「封面 + 内页」整体观感。
>
> **如何使用**：① 按内容类型在 `content-framework.md` 找到推荐风格 → ② 回本表取
> 「配色值 + 字体 + 构图 + 配图方式」→ ③ 喂给 `xls_image_builder.py` 对应函数渲染。
> 一个账号应**固定 2-3 个风格**形成视觉识别（见文末「视觉识别纪律」）。

## 二、八大家族详述（配色值 + 字体 + 构图 + 配图方式）

### A. 手绘家族（S01–S05）
- **配色**：纸黄 #f6f0e2 底 + 墨黑手写字 + 马克笔黄 #f2c65c / 墨绿 #5a8a6f + 红笔 #d8674f（≤3 处高亮）。
- **字体**：手写感（STKaiti/楷体）标题略歪；正文圆体保证清晰。
- **构图**：不规则手绘边框 `border-radius:225px 15px 225px 15px/15px 225px 15px 225px`；马克笔高亮 `linear-gradient(transparent 55%, rgba(242,198,92,.6) 55%)`；简笔 SVG 图标。
- **配图方式**：纯 HTML+CSS 渲染，无需 ImageGen（核心优势：零图床依赖、批量快）。
- **细分**：S01 指引（步骤/VS/清单/结构）/ S02 简笔插画（圆润扁平）/ S03 涂鸦漫画（对话框气泡）/ S04 儿童绘本（暖色厚涂）/ S05 手绘长图（竖向滚动信息）。

### B. 大字报/极简文字家族（S06–S10）
- **配色**：S06 大字报=黑底 #111 白字 + 暖金/珊瑚重点；S07 金句=墨蓝→黑渐变 + 金字；S08 极简=奶白大留白 + 单墨字 + 1 金点；S09 报纸=新闻纸 #ece5d8 + 黑字 + 朱红 #c0392b 刊头；S10 霓虹=近黑 #0a0a12 + 霓虹青 #2ee6d6 / 品红 #ff3ea5 发光字。
- **字体**：标题超粗黑体（800–900）；S09 用衬线（宋/Georgia）做刊头；S10 用等宽/圆体 + text-shadow 发光。
- **构图**：S06 字占画面 60–70%，信息 ≤8 字；S07 居中大字 + 细线分隔；S09 多栏 + 刊头横线；S10 居中发光字 + 暗噪点底。
- **配图方式**：纯 CSS（S10 可加暗噪点 SVG 滤镜）。无需 ImageGen。

### C. 杂志/编辑家族（S11–S14）
- **配色**：S11 时尚=米白 #faf8f3 + 墨字 + 1 跳色（珊瑚/墨绿）；S12 拼贴=多素材撕边 + 胶带感；S13 复古=暖橙棕 #c98a5a / 芥黄 #d9b54a + 颗粒；S14 瑞士=白底 + 黑字 + 1 原色（红/蓝）。
- **字体**：S11/13 衬线大标题（Playfair/宋）+ 无衬线正文；S14 Helvetica 风无衬线。
- **构图**：S11 大图留白 + 细线刊头 + 小字标注；S12 不规则拼贴 + 旋转贴纸；S13 双栏 + 复古分隔；S14 严格网格对齐 + 大字标题跨栏。
- **配图方式**：S11/12/13 需 ImageGen 实景大片或拼贴素材（去水印）；S14 图标+文字为主，可无图。

### D. 国风/中式家族（S15–S19）
- **配色**：S15 水墨=宣纸 #f5f1e8 + 焦墨 #2b2b2b + 朱砂 #9e3a2f；S16 新中式=黛青 #2f4858 + 朱红 #c0392b + 留白；S17 古籍=宣黄 #e8dcc0 + 墨字 + 朱批；S18 敦煌=石青 #2a6b8a / 土红 #b5482f / 金 #c8a45c；S19 节气=当季色（春绿/夏青/秋金/冬蓝）+ 民俗红。
- **字体**：书法/楷体标题（S15/17/18 用行楷/隶感）；S16 用现代黑体配竖排。
- **构图**：S15 大面积留白 + 一笔水墨 + 竖排题款；S16 现代留白 + 朱红印章式落款；S17 竖排活字 + 朱批圈点；S18 满幅矿物色块 + 描金线；S19 节气物候插画 + 红幅标题。
- **配图方式**：S15/18 可 ImageGen 水墨/敦煌感图（去水印）；S16/17/19 以字体+版式为主，可无实景图。

### E. 知识卡/信息图家族（S20–S25）
- **配色**：S20 知识卡=白底 + 墨蓝标题 + 墨绿图标 + 暖金强调；S21 数据=奶白/深蓝底 + 大数字墨绿/珊瑚；S22 对比=左灰冷 ✗ / 右暖亮 ✓；S23 清单=白卡 + 墨绿勾；S24 流程=墨蓝步骤 + 金连接；S25 导图=中心墨蓝 + 辐射墨绿。
- **字体**：无衬线粗体标题 + 清晰正文（信息层级靠字号/色块，不靠花字）。
- **构图**：网格对齐、信息分层（主>次>辅助）、超级符号（✓灯泡📅降低理解成本）。
- **配图方式**：纯 CSS（图表/图标用 SVG 或 Unicode），零 ImageGen。最适批量生产。

### F. 达芬奇线条/素描家族（S26–S29）
- **配色**：S26 手稿=羊皮 #efe6d0 + 墨褐 #3a2e1f 线 + 朱红标注；S27 蓝图=深蓝 #0d2b4e 底 + 白/青线；S28 科学=白底 + 细黑标注线 + 1 强调色；S29 炭笔=灰纸 #e9e7e2 + 炭黑。
- **字体**：衬线/手写标注体（仿手稿注解），配细线箭头标注。
- **构图**：S26 解剖/机械感线条 + 手写注解 + 比例尺；S27 网格 + 白线结构图；S28 剖视图 + 引线标签；S29 单色炭笔人物/场景。
- **配图方式**：S26/28/29 可 ImageGen 素描/手稿风图（去水印）后压 CSS 标注；S27 纯 CSS 网格。

### G. 抽象/艺术家族（S30–S35）
- **配色**：S30 几何=蒙德里安式原色块（红 #c0392b/蓝 #1f4e9b/黄 #f2c65c）+ 黑线；S31 孟菲斯=撞色（珊瑚/湖蓝/芥黄）+ 波点/锯齿；S32 极简抽象=2 色块 + 留白；S33 流体=柔和渐变（蓝绿粉）；S34 波普=高饱和 + 半调网点；S35 梦核=紫 #7b5cff / 粉 #ff7ec8 / 青 渐变 + 噪点。
- **字体**：S30/32 无衬线粗体；S31/34 圆体/卡通粗；S33/35 细体或发光。
- **构图**：S30 严格几何分割；S31 不规则图形堆叠 + 趣味；S32 大色块 + 居中字；S33 流动曲线；S34 网点底 + 粗框；S35 渐变雾 + 故障感字。
- **配图方式**：S33/35 可 ImageGen 抽象图；其余纯 CSS 几何即可。

### H. 照片/写实家族（S36–S40）
- **配色**：由照片主色决定，文字蒙版保证可读（暗渐变 + 白字 / 亮底 + 墨字）。
- **字体**：无衬线粗体压图，或手写体增温度（故事类）。
- **构图**：S36 情绪照片 + 底部暗蒙版 + 大字白标题（我们已有的 confession/story）；S37 胶片颗粒 + 漏光 + 时间戳；S38 产品平铺 + 干净背景 + 角标；S39 生活场景 + 字幕标签；S40 理赔截图/数据图 + 红框强调。
- **配图方式**：**必须 ImageGen 生成无字写实照片 → crop_watermark 去水印 → HTML 压排版文字**（base64 内嵌避免 file:// 失败）。

### I. 笔记本手账家族（S41）
- **配色**：浅蓝白底 `#EEF5FB` + 蓝色主色 `#4A90D9` + 金黄标题 `#F5C842` + 红/绿/黄三色编码徽章。
- **字体**：黑体/YaHei Bold 标题（900）+ 常规正文（400）+ 手写斜体备注（KaiTi Italic）。
- **构图**：左侧螺旋装订线（贯穿全图，签名元素）+ 顶部 mascot + 蓝幅金字大标题 → 虚线公告框 → N 个编号观点块（彩色徽章+pill标题+图标+表格+侧边备注）→ 蓝渐变底部总结+二维码。装饰体系=回形针⭐星星📎胶带·彩色圆点。
- **配图方式**：纯 CSS+SVG 渲染（螺旋线/表格/装饰全部代码绘制），mascot 可 ImageGen 卡通人物后 base64 或用 SVG 占位。零图床依赖，可批量生产。
- **定位**：信息密度最高的风格——政策解读/分级对比/复杂攻略的首选。与 S00 分工：S00 单点穿透（1张），S41 系统讲解（2-5张长图）。

## 三、视觉识别纪律（避免「风格乱」）

1. **一个账号固定 2–3 个家族**：如「**S00 卡通知识卡（核心固定）** + **S41 笔记本手账长图（第二固定）** + 手绘 S01」形成记忆点。S00 是科普/对比/避坑类内容的默认风格；S41 是政策解读/分级攻略/复杂科普的首选长图格式。
2. **统一三要素**：固定主色板 + 固定标题字体 + 固定封面版式（左上角标/底部署名条）。
3. **风格切换规则**：日常种草用手绘/知识卡；重大节点（养老/传承）用国风；年轻化话题用抽象/大字报。
4. **合规红线不变**：无论哪种风格，保险表述不承诺收益/不夸大理赔、提「赔」必标「以核定/条款为准」、AIGC 声明、末图才放企微码。

## ★ 卡通知识卡固定式规范（S00 · 核心风格 · 来自实战验证）

> **来源**：公众号「保险知识大科普」等账号的小绿书/图文知识卡片（用户 2026-07-19 提供参考并要求固化）。
> **定位**：小绿书 **第一核心固定风格**——科普/对比/避坑/方案推荐类内容的首选。
> **特点**：扁平卡通插画 + 圆角信息卡 + 四色编码系统 + 大标题要点列表，信息密度高但阅读轻松。

### S00 设计 DNA

| 维度 | 规范 |
|------|------|
| **底色** | 浅蓝渐变 `linear-gradient(180deg, #E8F4FC 0%, #F5FAFD 50%, #FFFFFF 100%)` 或 奶暖渐变 `#FFF8F0→#FFFDF8` |
| **主容器** | 白色圆角卡片 `border-radius:24px` + 软阴影 `0 4px 20px rgba(0,0,0,0.08)`，内边距 `24-32px` |
| **标题** | **超粗黑体 800-900**，字号最大（占画面 12-15%），纯黑 `#1a1a2e` 或深墨蓝 `#1a2332` |
| **副标题** | 中号常规体 `#666` 或 `#555`，位于标题下方 |
| **四色编码** | 🔵 蓝 `#2B7DD8`=信息/左侧/正确 · 🟠 橙 `#FF8C42`=强调/金额/右侧 · 🟢 绿 `#22C55E`=正确答案/CTA · 🔴 红 `#EF4444`=错误/X标记 |
| **插画** | 扁平卡通矢量（车/人物/图标）——友好圆润、非写实、粗轮廓线可选；用 CSS/SVG 内嵌或 ImageGen 生成后 base64 |
| **卡片组件** | 圆角矩形容器 `border-radius:16px`，有色边框(2-3px)或实色填充；头部彩色圆角标签(pill) |
| **要点列表** | 彩色圆点 bullet（与卡片色系一致）；关键数字/金额用橙色加大 |
| **高亮条** | 橙色圆角药丸条 `background:#FF8C42; color:white; border-radius:20px; padding:8px 20px` 放"核心一句话" |
| **底部总结** | 灰色居中文字 `#888`，一行收尾 |

### S00 三种子类型

#### S00-A 对比双栏卡（Comparison Card）
- **适用**：A vs B 对比（如 座位险 vs 驾乘险 / 社保 vs 商保 / 定期 vs 终身）
- **构图**：
  1. 顶部：超大黑字标题 + 灰色副标题
  2. 高亮条：橙色药丸一句话
  3. 视觉中心：**两个卡通插画元素左右并列**（各带蓝色/橙色标签 badge）
  4. 主体：**左右两栏卡片**（左蓝框右橙框，等宽）
     - 每栏头部：彩色 pill 标签（蓝/橙底白字）
     - 4-5 个 bullet 要点（彩色圆点）
     - 关键数字橙色加粗
  5. 底部：灰色总结一行
- **参考**：用户截图 Image 1（车险座位险 vs 驾乘险）

### S00 对比度铁律（⚠️ 2026-07-19 修复验证）

> **教训**：scenario 横幅卡片曾出现"白字(`#fff`) + 白底(`#fff`/`rgba(255,255,255,0.9)`)"导致文字完全不可见。

**所有风格必须遵守的对比度底线：**

| 元素类型 | 最低对比度要求 | 禁止组合 |
|----------|----------------|----------|
| 正文文字(≥14px) | 文字色与底色亮度差 ≥ 4.5:1 (WCAG AA) | 白字 `#fff` + 白底 / 浅色字 `< #888` + 白底 |
| 标题文字(≥16px) | 亮度差 ≥ 3:1 (WCAG AAA) | 浅蓝/浅灰标题 + 浅色同系底 |
| 次要说明(≤13px) | 必须 ≥ `#777`，禁止 `#aaa` / `#999` / `#E0ECFE` 等极淡色 | — |
| badge/pill 内文字 | badge 有实色背景时可用白字；badge 背景为淡色/透明时**必须用深色字** | 半透明底+白字（在不确定底层色时必崩） |
| footer/disclaimer | ≥ `#777` | `#888`/`#999` 在白色/浅灰底上 |

**检查方法**：每写完一个渲染函数的 CSS → 用"去色测试"（把截图转灰度）→ 能看清每个字才算过。

## ★ 笔记本手账长图固定式规范（S41 · 来自实战验证）

> **来源**：公众号大号「保险分级制度正式落地」等政策科普长图（用户 2026-07-20 提供参考并要求固化）。
> **定位**：小绿书 **第二固定风格**——政策解读/条款变化/分级对比/复杂攻略类内容的**首选长图格式**。
> **特点**：笔记本纸张底 + 螺旋装订 + 卡通人物 mascot + 编号观点块 + 表格 + 侧边备注，信息密度极高但阅读体验轻松，收藏欲强。

### S41 设计 DNA

| 维度 | 规范 |
|------|------|
| **底色** | 浅蓝白 `#EEF5FB` 或 `#F0F6FC`，模拟笔记本纸张质感；可加细微纸纹理 |
| **左侧装订** | 金色螺旋线圈（CSS 伪元素+border-radius圆环，竖向排列），**签名识别元素** |
| **主标题区** | 蓝色横幅/丝带 `background:#4A90D9` + **金黄粗体字** `#F5C842` 或 `#FFD54F`，字号超大 |
| **Mascot** | 卡通人物插画（眼镜男孩/职业形象），位于左上角标题旁，带小徽章/P1标签 |
| **装饰体系** | 回形针📎 · 星星⭐ · 胶带条(washi tape效果) · 彩色实心圆点(黄/蓝/粉) · 喇叭/灯泡/剪贴板图标 |
| **公告框** | 虚线蓝色边框 `border:2px dashed #4A90D9` + 圆角 + 喇叭图标 + 浅蓝填充 `rgba(74,144,217,0.08)` |
| **内容块结构** | **编号观点块 N 个**（①②③…），每块含：彩色数字徽章 + 粗体标题(pill色标) + 图标 + 正文 + 可选表格 |
| **编号徽章** | 彩色圆形/星形：黄⭐(重点) / 绿●(中性) / red●(警示)，带白色数字 |
| **表格风格** | 白底 + 淡彩表头行（粉`#FFE0E0`/橙`#FFF3E0`/绿`#E8F5E9`交替）+ 细灰线网格 `#E0E0E0` |
| **侧边备注** | 右侧或底部浅色便签框 `background:#FFFDE7` 或 `#FFF0F0`，手写感斜体小字 |
| **底部区** | 蓝渐变背景 `linear-gradient(180deg, #4A90D9, #357ABD)` + 白字总结 + 二维码位 |
| **三色编码** | 🔵 蓝 `#4A90D9`=主色/标题/边框 · 🟡 金黄 `#F5C842`=主标题字/星级 · 🔴 红 `#EF4444`=警示/重要标记 · 🟢 绿 `#22C55E`=正面/正确 |
