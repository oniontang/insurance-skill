## 一、微信公众号（含小绿书/图片消息，同一套规则）

### 1.1 导流私域限制（核心红线）
- 文章正文**放二维码、微信号、企微码、外链**会被**限制公域推荐**，新号尤甚，严重者账号限流。
- **合规替代方案**：
  - 用「阅读原文」挂外链（服务号可配，订阅号有限）
  - 引导用户点「作者头像/账号名片」关注，在菜单栏/自动回复承接
  - 用「公众号主页简介 + 私信自动回复」承接，不碰正文硬导流
- **结论**：保险类公众号**正文不出现任何二维码/微信号**；如需引导，用"关注后后台回复关键词"等软引导。

### 1.2 AIGC 内容声明
- 微信对**低价值 AIGC（AI 占比高且不声明）不鼓励推荐**。
- 正文/文末标注「AI 辅助创作，经人工审核」类声明，提升推荐权重、降低判低质风险。

### 1.3 内容合规（保险）
- 不承诺收益、不夸大理赔结论、不贬低同业；
- 凡提"赔/领"必须标注"以保险公司核定及保险合同条款为准"；
- 结论性判断仅作参考（继承 claims-assist 红线#0）。

### 1.4 图片消息（小绿书）
- 接口 `news_image_message/add`，支持 `pic_crop_235_1`(2.35:1) / `pic_crop_1_1` 封面裁剪；
- 正文图片须先上传微信图床（外链图会被过滤）；
- 同样受 1.1 导流限制约束。

## 二、小红书

### 2.1 私域导流红线（最高风险）
- 《交易导流违规管理细则》(2025-03-12 生效)：笔记/评论/资料**禁止放微信号、二维码、外链、口令、截图导流**。
- 处罚梯度：警告 → 限流 → **永久封号**。
- **合规引流唯一路径**：小红书店铺 / 直播间购物车 / 官方留资组件 / 私信通 / KOS 企微直连。
- **结论**：小红书笔记正文/评论**绝不放二维码与微信号**；引导用"主页简介/评论区置顶官方组件"。

### 2.2 社区规范
- 标题党、医疗绝对化用语（最佳/根治/100%）、虚假科普会被限流；
- 保险内容须合规，不承诺收益、不贬低同业；
- 封面党需真实对应内容，勿标题与正文不符。

### 2.3 发布方式
- **无官方草稿箱 API**：只能本地生成"发布包"（内容+配图），由你在小红书专业号后台手动发布。
- 发布包含：标题、正文、话题标签、封面文案、9图规划（标注每图内容）、合规自检。

## 三、三平台分工（内容矩阵）
| 平台 | 定位 | 导流策略 | 发布 |
|------|------|----------|------|
| 公众号 | 微信长文·深度信任主阵地 | 软引导(菜单/后台关键词)，不碰正文硬导流 | API 推草稿箱 |
| 小绿书 | 微信内轻图文·私域闭环 | 末图可放企微二维码(微信生态内允许)，强导流 | API 推草稿箱 |
| 小红书 | 独立 APP·公域种草 | 严禁硬导流，用官方组件 | 手动发布包 |

> 注：小绿书因在微信生态内，末图放企微二维码属平台内闭环，较公众号宽松；但仍避免正文文字硬塞微信号。
