# 小绿书内容框架（Content Framework）

> **核心认知（来自生态调研）**：
> 1. 小绿书 = 微信「图片消息/贴图号」，3:4 竖图 + 短文案(≤1000字,实测200–300字最佳)，最多9图，**零粉有公域推荐**（看一看/搜一搜/订阅流加权，同号阅读量是长文 2–3 倍）。
> 2. 封面决定 70% 点击：字要大(≤15字/主标题占60–70%面积)、高对比配色、真实感优于精修、有情绪/表情。
> 3. 正文黄金结构：**痛点开头 → 方法干货 → 案例验证 → 行动指引**；每段≤100字，留「呼吸感」。
> 4. **保险赛道爆款规律**（小红书投放数据）：把产品藏进「场景」别开门见山；理赔故事转化>产品介绍 3倍；具体金额公式>泛科普；质疑式标题更高点击；「省钱/避坑」是强钩子；特殊人群(早产/带病)是蓝海。
> 5. **内容要「泛保险」+ 生活化 + 结合民生新闻**，纯讲保险没人看。

## 〇、从小红书保险种草大博主迁移的实战规律（内容大脑的底层方法论）

> 小绿书 = 微信生态里的"小红书"。小红书保险大博主的种草写法、内容策划、人设运营，是**直接可迁移的教科书**。以下规律来自小红书爆款拆解 + 保险垂直账号（自保叔、花花姐说险、叶云燕等）研究，已映射到我们的 style-archive / 引擎。

### 0.1 种草三板斧（封面 + 标题 + 正文）及其小绿书映射

| 板斧 | 小红书铁律 | 小绿书落地做法 |
|------|-----------|----------------|
| **封面** | 0.3秒定生死：视觉冲击 + 信息精准 + 情绪共鸣 | 选 style-archive 封面范式（6式之一），大字≤15字占1/3、高饱和≤3色、真实感>精致感 |
| **标题** | 痛点/利益 + 场景 + 情绪钩子；关键词前置 | 标题公式套用（见0.3）；图文消息主标题=封面大字，副标题进首图 |
| **正文** | AIDA：注意→兴趣→欲望→行动；前3行留人 | 黄金三段式（见0.4）；每图一句核心信息，3–6图黄金 |

### 0.3 标题 8 公式（保险垂直改造版，可直接套）

1. **数字公式**：「3个方法 / 5步搞定 / 一年省X钱」→ 「买车险前必看3件事」
2. **反常识公式**：「你以为的XX其实是错的」→ 「只买座位险？出事才发现差几十万」
3. **对比公式**：「从XX到XX只用了X天」→ 「从裸奔到配齐，这家人只花了300」
4. **痛点公式**：「还在为XX发愁？」→ 「还在为"先保大人还是孩子"纠结？」
5. **时间公式**：「30天/1周/3分钟」→ 「3分钟搞懂重疾险和医疗险」
6. **身份公式**：「XX必看」→ 「宝妈必看 / 房贷族必看 / 新手司机必看」
7. **利益公式**：「学会了省下XX元」→ 「这样配，一年省下2000保费」
8. **案例公式**：「我是如何XX的」→ 「我是怎么帮客户把理赔从拒赔翻成88万的」
- **保险垂直约束**：关键词前置（"车险/重疾/养老"卡搜索）；禁用"最/第一/100%"等绝对化词（限流+合规）；长度≤20字，移动端友好。

### 0.3b 标题进阶方法论（劲爆悬念·痛点对号·冲突反差 · 来自娱乐报刊+公众号10万+研究）

> **来源**：2026-07-19 专项研究——三线并行搜「娱乐报刊劲爆标题」「小红书保险爆款标题」「公众号10万+标题法则」，提炼可合规迁移的"炸裂"技法。
> **核心原则**：站在用户/读者角度——让目标人群看到标题产生"这说的就是我"或"必须点进去看答案"的冲动。
> **合规底线**：不虚构个人拒保/理赔经历、不承诺"一定买得上"、不编造虚假案例；保险内容标"以核保结论为准"、医疗内容标"科普不代表诊疗建议"；禁用极限词（最/第一/绝对）；标题与正文必须匹配（防标题党掉粉）。

#### 一、六大劲爆标题流派

| # | 流派 | 技法 | 结构 | 保险示例 |
|---|------|------|------|----------|
| **F1** | 悬念留白型 | 只说一半、抛反常结果不给答案 → 制造信息缺口 | 反常现象/极端结果 + 省略号/问号/留白 | 「体检单有箭头，保险就废了？」「同事查出肺结节，我们都以为他买不了，结果……」 |
| **F2** | 冲突反差型 | 认知矛盾 / 数字对比 / 身份反差 → 打破常识 | A vs B 矛盾体 / 低起点→高结果 | 「医生说没事，保险公司却拒保？这3类人反而能买」|
| **F3** | 痛点对号入座 | 细分人群标签 + 具体痛点场景 → "说的就是我" | 人群标签(越细分越好) + 场景 + 痛点描述 | 「有体况，保险空着？」「体检报告一摊红，你是不是也以为自己'买不了保险'？」 |
| **F4** | 数字具象型 | 数字越具体越有点击欲 + 结果承诺 | 数字(3-7) + 动作/时间 + 具体结果 | 「3类常见体况，投保通道在这里」「5个误区，90%的人踩过」 |
| **F5** | 情绪触发型 | 强烈情绪词 + 共鸣场景 → 冲动点击 | 情绪词(焦虑/后悔/绝了/救命) + 场景 | 「最怕体检季！报告出来，保险就跟我无关了？」 |
| **F6** | 场景代入型 | 具体细节画面 → 一秒进入剧情 | 时间/地点/动作 + 核心冲突 | 「凌晨翻体检报告，第3页那行红字让我清醒了」 |

#### 二、封面短标题 vs 正文长钩子（双标题策略）

小绿书有**两个标题位**，要分开设计：

| 位置 | 长度 | 功能 | 技法优先级 |
|------|------|------|-----------|
| **封面大字** | ≤15字 | 视觉冲击、0.3秒抓眼球 | F3痛点对号 > F1悬念留白 > F2冲突反差 |
| **正文首句钩子** | ≤30字 | 信息流里吸引点击 | F1悬念留白 > F3痛点对号 > F5情绪触发 |

> **封面铁律（来自小红书迁移）**：≤15字占封面1/3面积、高对比配色、统一视觉识别、真实感>精致感。

#### 三、娱乐报刊"无中生有"技法的合规化转译

| 娱乐报刊原法 | 核心逻辑 | 保险合规版 |
|-------------|---------|-----------|
| "30杯冰美式"代替"耍大牌" | 细节具体化=画面感 | "第3页那行红字"代替"体检有问题" |
| "凌晨三点淋雨"代替"分手" | 场景冲突=情绪张力 | "凌晨翻体检报告"代替"担心买不了保险" |
| "昔日闺蜜成情敌"代替"三角恋" | 身份反转=吃瓜雷达 | "医生说没事，保司却拒保"代替"核保严格" |
| "话讲一半留一半"卖关子 | 信息缺口=必须点开 | "结果……""其实很多人搞反了"（必须有干货接住） |
| 极端化词汇("十大狠招") | 升维词=吸睛 | "保险绝缘体"替代"买不了"；"被劝退"替代"被拒保" |

#### 四、组合拳模板（直接套用）

**模板1：痛点+悬念+反转（万能型）**
> [人群痛点场景] + [你以为的结论] + [反转暗示]
> 例：「体检报告一摊红，你是不是以为自己'买不了保险'？其实很多人搞反了」

**模板2：冲突+数字+利益（科普型）**
> [认知矛盾] + [数字] + [解决方案暗示]
> 例：「医生说没事，保险公司却说不行？这3类体况反而能买」

**模板3：场景+留白+CTA（种草型）**
> [具体场景细节] + [省略号/问号] + [行动暗示]
> 例：「同事查出肺结节，我们都以为他买不了保险，结果……」

**模板4：身份+数字+清单（收藏型）**
> [细分人群必看] + [N个要点] + [效果承诺]
> 例：「有结节的人必看！3步搞清自己还能不能买」

#### 五、避坑指南

1. **别做标题党**：悬念必须有干货接住，否则高点击+高退场率=账号降权
2. **别虚构个人经历**：不能用"我被拒保3次""理赔88万"等编造故事（合规红线）
3. **别用过度夸张**："震惊!""绝对!""100%"已过时且违规
4. **别超20字**（正文标题）：移动端折叠影响点击
5. **别忘了关键词前置**：保险垂直领域，"结节/高血压/医疗险/带病投保"等搜索词放前半段

### 0.4 正文黄金三段式（AIDA 落地，适配小绿书 3–6 图）

```
[图1 结果/痛点] 第一张放"结果或痛点"，不铺垫。"邻居车祸，座位险只赔2万"
[图2 钩子] 痛点/场景开头≤50字："你是不是也只买了座位险？"
[图3-5 价值] 分点干货：对比/步骤/清单，每点≤100字，粗体核心词
[图6 行动] 明确下一步 + 互动钩子（评论区提问/收藏）
[末图 私域] 企微码/关注引导（微信内宽松，见0.5）
```
- 前100字在信息流直接展示 → 必须覆盖核心关键词 + 说清"这篇帮你解决什么"。
- 每段≤3行、口语化像朋友聊天、善用✅🔸等符号分隔。

### 0.5 保险垂直打法（小红书大博主共识）

- **场景切入 > 开门见山**：别一上来讲保额条款，从生活片段带出（"刚当妈那年…""租房青年要不要买意外险"）。
- **条款变人话**：用对比图/手绘/流程图降门槛（对应 S01/S24/S25 手绘与导图）。
- **真实案例传温度**：讲理赔真实故事（隐去姓名地点脱敏），情感感染力 > 参数对比。
- **温和引流私域**：结尾"有类似困惑欢迎聊聊~""更多避坑在我的公众号"；**小绿书末图可放企微码**（微信内闭环宽松，比小红书更直接）；绝不直留电话二维码硬广。
- **人设即信任**：固定"身份+价值"昵称、统一视觉识别（固定2–3风格+署名条）、持续科普建立"靠谱保险搭子"人设。

### 0.6 标签策略（影响搜索曝光）

- **3 个精准垂直标签 > 10 个热门标签**（曝光高约40%）；滥用热门反而降权。
- 结构：主关键词 + 需求场景 + 人群，如 `#车险避坑 #座位险 #新手司机`。
- 小绿书图文消息：正文末尾 2–3 标签；图片上也可压关键词标签增搜索曝光。

### 0.7 实战参考案例拆解（用户提供的公众号文章）

**原文**：《只买座位险，车祸后仅赔2万，驾乘险才刚需》（公众号长图文）
**可迁移结构**（小绿书化改造方案）：
- 标题（已验证有效）：痛点+结果反差「只买座位险，车祸后仅赔2万，驾乘险才刚需」
- 原文骨架：`核心一句话 → 5个核心差别 → 3个高频误区 → 分人群选购方案 → 话题标签 + 服务群引导`
- **小绿书改造映射**：
  - 封面（情绪/对比型）：「只买座位险的人，出事才懂差几十万」→ 范式4反差 / S22
  - 图2（钩子）：「车险续保，你是不是只勾了座位险？」
  - 图3–4（对比干货）：5个差别压成 2 张知识卡（S20/S23）→「属性不同/赔付门槛/保额保费…」
  - 图5（误区）：3个误区清单卡（S23 清单勾选）→「有座位险就万事大吉❌」
  - 图6（分人群）：分人群方案卡（家用/通勤/营运/预算充足）→ S24 流程或 S23 清单
  - 末图（私域）：企微码 + 「专属车险方案，免费帮你算」
- **启示**：这类"对比拆解 + 分人群方案 + 私域群引导"是保险小绿书最稳的爆款骨架之一，已固化进选题库（见 topics.md 的"对比拆解型"）。

## 二、选题库机制（持续更新）

**选题三大来源（闭环）**：
1. **泛保险生活化**：从「家庭财务/健康生活/人生阶段」切入，不硬讲保险。
   - 词根：月光/备孕/房贷/父母养老/孩子入学/换工作/体检异常/装修/出行……
2. **民生新闻/热点**：建立「热点→保险角度」映射表，抢占窗口期（如五一前布局旅行险）。
   - 维护 `references/hotspot-map.md`（热点事件 → 可写角度 → 推荐风格 → 标题公式）。
3. **微信生态爆款复刻**：每周用 wechat-eco-search 搜「保险 小绿书/图片消息」「保险 避坑」高赞，仿写不搬运（改写+换图+本地化）。

**选题公式（标题）**：`痛点/数字/反差 + 结果 + 情绪`

- 「300块配齐一家三口，这是我见过最省的方案」
- 「我爸走后第7天，才翻到那张保单」

**标题类型库**：结果型 / 痛点型 / 清单型 / 反差型 / 质疑型（「XX真的有必要吗？」点击率更高）。

## 三、写作 SOP（黄金三段式，适配小绿书短文）

```
[封面] 大字标题 ≤15字 + 高对比 + 1情绪钩子
```
