# 小绿书封面设计系统（核心竞争力）

> 小绿书像小红书一样**特别吃封面**。封面决定 80% 的点击。
> 本文件是封面设计的"作战手册"——每次生成封面前必须先选范式、定情绪、配版式。
> 封面 = **情绪价值感性图**（不是干巴巴压张字），必须有强设计感。

---

## 一、封面设计的三条铁律

1. **一眼看懂 + 一秒心动**：3 米外看得清主标题，且情绪能瞬间戳中。
2. **情绪 > 信息**：封面负责"勾住人"，专业内容留给后端手绘图。封面只给一个情绪钩子。
3. **留白与字重对比**：大字要够大（占画面 1/3 以上），小字克制。忌满屏堆字、字号平均。

## 二、封面规格（微信图片消息）

| 用途 | 尺寸 | 说明 |
|------|------|------|
| 主封面（推荐） | **1080×1440（3:4）** | 竖版，手机信息流最抢眼，同小红书 |
| 封面裁剪 235:1 | 1080×460 | 图片消息 `pic_crop_235_1` 用 |
| 方形备选 | 1080×1080（1:1） | `pic_crop_1_1` 用 |

> 渲染出 3:4 主封面后，推送时按需裁出 2.35:1 / 1:1 缩略。

## 三、封面六大范式库

> 每次按选题的"情绪内核"选 1 个范式。下面给出：适用场景 / 构图 / 字号 / 配色 / 情绪触发点 / 保险示例标题。

### 范式 1 · 戳心自白型（Confession）
- **情绪内核**：第一人称的遗憾/后怕/顿悟，让人代入"这会不会是我"。
- **适用**：真实故事、身后事、家庭责任、突发疾病。
- **构图**：情绪照片打底（压暗 55-70%）+ 中下部大字白色标题 + 底部一行小字副题。
- **字号**：主标题 76-92px 超粗；副题 26-30px。
- **配色**：暗色照片 + 纯白主字 + 一抹暖金（#c8a45c）点缀关键词。
- **示例**：
  - 「我爸走后第7天，我才在抽屉里翻到那张保单」
  - 「38 岁那年，我第一次认真想'万一我不在了'」

### 范式 2 · 数字冲击型（Number）
- **情绪内核**：用一个反常识数字制造好奇+焦虑。
- **适用**：科普、避坑、数据揭示。
- **构图**：浅色纯色/微纹理底 + 超大数字（占画面 1/2）+ 短标题压在数字上或下。
- **字号**：数字 200-300px；标题 44-52px。
- **配色**：奶白底（#f7f3ec）+ 墨绿/深蓝大数字 + 深灰标题；数字可用描边或半透。
- **示例**：
  - 「90% 的家庭，保险买错了顺序」
  - 「先给孩子买？错。第 1 个该保的是 TA」

### 范式 3 · 灵魂拷问型（Question）
- **情绪内核**：一个直击软肋的问句，让人停下来想。
- **适用**：唤醒需求、责任叩问、观念冲突。
- **构图**：大面积留白 + 居中大字问句 + 角落一个手绘小元素（问号/小人/箭头）。
- **字号**：问句 60-72px；无副题或极短。
- **配色**：浅底（奶白/浅灰蓝）+ 深墨字 + 手绘线条点缀（细）。
- **示例**：
  - 「如果明天你不在了，家人找得到保单吗？」
  - 「你给车买了全险，给自己呢？」

### 范式 4 · 反差对比型（Contrast）
- **情绪内核**：同一处境两种结局，制造强烈落差。
- **适用**：赔与不赔、买对买错、有无规划。
- **构图**：左右或上下分割（冷色✗ / 暖色✓）+ 中间一道分割线 + 两组短标签。
- **字号**：核心对比词 54-64px；标签 24-28px。
- **配色**：左灰冷 + 右暖亮；或 ✗红灰 / ✓墨绿。
- **示例**：
  - 「同样是重疾，她赔了 88 万，他一分没赔」
  - 「有规划 vs 没规划：差的不是钱，是一个家的底」

### 范式 5 · 清单预告型（Checklist）
- **情绪内核**：干货预告 + "收藏"暗示，制造"怕错过"。
- **适用**：避坑清单、必看要点、选择指南。
- **构图**：顶部标题条 + 3 个要点缩影（编号/勾选）+ 底部"建议收藏"暗示。
- **字号**：标题 52-60px；要点 26-30px。
- **配色**：浅底 + 墨绿标题 + 金色编号；干净利落。
- **示例**：
  - 「买保险前必看：这 3 件事没搞懂，别下单」
  - 「一张图看懂：家庭保单该按什么顺序配」

### 范式 6 · 温情故事型（Story）
- **情绪内核**：一个有画面感的故事切片，温暖而戳人。
- **适用**：客户故事、亲情、守护、传承。
- **构图**：情绪照片（暖光）+ 故事感标题（可带引号）+ 小字点出"真实故事"。
- **字号**：标题 62-76px；标注 22-26px。
- **配色**：暖色照片 + 米白字 + 金色标注。
- **示例**：
  - 「她把最后一份礼物，藏进了一张保单里」
  - 「爸爸没留下多少话，却留下了一份'安排'」

## 四、封面文字排版规范

- **主标题**：最多 2 行，每行 ≤12 字；关键词用金色/加粗强调 1-2 处。
- **字体**：中文用思源黑体/苹方 800 粗；情绪自白/故事型可用书法/手写感字体增温度。
- **对比度**：字压在照片上必须加暗渐变/蒙版，保证可读（暗底白字或亮底墨字）。
- **忌**：忌居中堆满、忌字号平均、忌花哨描边、忌超过 3 种颜色。

## 五、配色主板（保险·信任×温度）

| 名称 | 色值 | 用途 |
|------|------|------|
| 墨蓝（主） | #1f2a44 | 主字/深底，专业信任 |
| 暖金（点缀） | #c8a45c | 关键词/装饰线，高级感 |
| 奶白（底） | #f7f3ec | 浅色封面底 |
| 墨绿（数字/理性） | #2f5d50 | 数字冲击/清单，稳重 |
| 暖珊瑚（情绪） | #d8674f | 情绪强调/警示，克制用 |

## 六、封面自检清单（出图前过一遍）
- [ ] 选对范式了吗？（情绪内核和选题匹配）
- [ ] 3 米外能看清主标题吗？（字够大）
- [ ] 有一个明确的情绪钩子吗？（不是陈述句）
- [ ] 颜色 ≤3 种、字压图有蒙版吗？
- [ ] 关键词有金色/加粗强调吗？
- [ ] 有没有硬导流文字？（封面不放微信号/二维码）

## 七、封面生成工作流（供 Stage 4 调用）
1. 定选题情绪内核 → 从 6 范式选 1（可让用户二选一）。
2. 情绪型范式（1/6）→ 先 ImageGen 出无字情绪照片 → 去水印 → HTML+CSS 压排版文字。
3. 理性型范式（2/3/4/5）→ 纯 HTML+CSS 渲染（配色+大字+手绘小元素）。
4. 用 `xls_image_builder.py` 对应范式函数渲染 → 输出 1080×1440 PNG。
5. 过"封面自检清单" → 不过重做。

## 八、从小红书迁移的封面铁律（实战约束，必守）

> 来自小红书爆款封面拆解（决定 70%–80% 点击率）。小绿书同样吃这套。

1. **真实感 > 精致感**：像"朋友拍的"（有场景/有细节/有生活感）> 硬广大片。能用真实照片（ImageGen 写实场景）就别用纯字版，点击率天然高。
2. **人物出镜 +40%**：有人物/真人的封面点击率比纯图文高约 40%（小红书数据）。情绪型封面优先用写实人物场景图（范式1/6 + ImageGen 实景）。
3. **高饱和、≤3 色**：红/黄/橙等暖色更易被看见；黄底红字、蓝底白字冲击强；**慎用灰/浅粉/淡绿**（易被划走）。配色主板（墨蓝/暖金/奶白/墨绿/暖珊瑚）已满足，勿超 3 色。
4. **大字 ≤15 字、占画面 1/3 以上**：缩到手机尺寸仍清晰可读；缩小测试不过重做。
5. **信息密度高（一眼看懂有用）**：不用看不懂的意境图/模糊远景。好封面标准=用户扫一眼就知道"这对我有用"。
6. **4 种封面类型任选其一**：对比型 / 清单型 / 场景型 / 问题型（见 content-framework 0.2 映射）。每次只打一种，别混。
