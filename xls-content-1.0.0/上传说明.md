## ② 详细介绍（粘贴到"介绍/详情"框）

小绿书创作器是面向保险经纪人的微信「图文/图片消息」内容生产线。它把"小红书式种草"的方法论迁移到微信生态，专门解决保险内容"没人想点、点了留不住"的痛点。

**【核心定位】知识性 × 情绪性 双载体**
- 封面图 = 情绪价值感性图（核心竞争力，特别吃封面）：用 40+ 套视觉风格 + 卡通知识卡，0.3 秒勾住读者。
- 后端图 = 手绘风专业指引图：把保险条款、方案、避坑画成一眼看懂的图。
- 文案 = 先情绪挑逗、再专业指导，≤200 字，口语化、去 AI 味。

**【已内置资产】**
- 视觉风格归档库（40 式 · 9 大家族）：手绘 / 大字报 / 杂志 / 国风 / 知识卡 / 达芬奇线条 / 抽象 / 照片写实 / 卡通知识卡，每式含配色值、字体、构图、配图方式、引擎映射。
- 标题方法论库：含"炸裂标题"6 大流派（悬念留白 / 冲突反差 / 痛点对号 / 数字具象 / 情绪触发 / 场景代入）+ 双标题策略 + 娱乐报刊合规化技法。
- 内容框架 + 选题库：10 类内容 × 风格映射 × 选题方向（泛保险 + 民生新闻 + 小红书复刻 + 分人群矩阵）。
- 渲染引擎 `scripts/xls_image_builder.py`：46 个渲染函数覆盖全 40 式 + 卡通知识卡（Playwright 高清截图，零图床依赖）。
- 推送组件 `scripts/push_wechat_draft.py` + `scripts/crop_watermark.py`：一键推微信草稿箱、AI 图去水印。

**【六阶段生产线】**
选题策划 → 提纲确认(封面方向必确认) → 素材文风 → 初稿(去AI味) → 配图(封面情绪图+手绘指引图) → 合规+微信规则 → 推草稿箱。

**【合规护栏】**
保险内容不承诺收益、不夸大理赔、不贬低同业；提"赔/领"必带"以保险公司核定及合同条款为准"；医疗科普不绝对化用语；结论仅作参考。

**【适用人群】**
保险经纪人 / 代理人 / 团队长，想用微信图文做私域种草但不想自己抠图排版的人。

**【最小使用示例】**
用户："帮我写条小绿书，讲带病也能买医疗险"
→ AI 走六阶段，产出 5-9 张图 + ≤200 字文案 + 推草稿箱，末图可放企微码做私域钩子。
