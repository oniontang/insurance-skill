# 输出结构校验与重试规则

本文件用于把 `陈庚-销售复盘` 的输出稳定在同一套结构里。

## 1. 必填模块

| 模块 | 要求 | 缺失处理 |
|---|---|---|
| 输入校验 | 必填 | 补写字段状态和缺口 |
| 一句话判断 | 必填 | 用 1-2 句给出当前结论 |
| 沟通摘要 | 必填 | 缺失时重写本模块 |
| 事实推断分离 | 必填 | 缺失时重写本模块 |
| 客户阶段判断 | 必填 | 缺失时重写本模块 |
| 销售卡点 | 必填 | 缺失时重写本模块 |
| 沟通表达诊断 | 必填 | 缺失时重写本模块 |
| 下一步动作 | 必填 | 缺失时重写本模块 |
| 可复用经验 | 必填 | 缺失时重写本模块 |
| 依据与缺口 | 必填 | 区分事实、判断、待确认项 |
| 下一步动作 | 必填 | 给 1-3 个动作 |
| 边界提醒 | 必填 | 删除确定承诺 |

## 2. 输出状态

| 状态 | 条件 | 下一步 |
|---|---|---|
| `pass` | 必填模块完整，边界清楚 | 可交付 |
| `retry` | 缺模块、结构散、越界表达 | 按模板重写一次 |
| `needs_review` | 重写 2 次仍不合格 | 交给人工复核 |

## 3. 超时和重试

- 单次生成建议上限：90 秒。
- 最多重写：2 次。
- 第 1 次缺模块：只补缺失模块。
- 第 2 次仍缺模块：重写完整答案，不继续扩写旧答案。
- 遇到材料冲突：停止终稿，列冲突点。

## 4. 校验脚本

- `scripts/output_validator.py`：检查输出是否包含必填模块。
- `scripts/retry_policy.py`：根据校验结果返回 `pass`、`retry` 或 `needs_review`。
