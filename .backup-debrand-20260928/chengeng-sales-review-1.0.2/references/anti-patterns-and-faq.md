# 反模式与 FAQ

本文件记录 `陈庚-销售复盘` 的常见错误用法和正确处理方式。

## 1. 常见反模式

| 错误用法 | 为什么错 | 正确处理 |
|---|---|---|
| 只给一句抽象要求，就要完整终稿 | 缺少场景和对象，输出会漂 | 先给缺口清单和最小追问 |
| 把待确认内容写成确定事实 | 会误导顾问和客户 | 标成待确认，并说明需要核对什么 |
| 直接替用户做最终承诺 | 超出保险顾问表达边界 | 改成条件判断、材料依据和下一步动作 |
| 把内部分析原样发给客户 | 客户会看到不该看到的推理过程 | 拆成客户版和顾问版 |
| 为了完整而堆很多模块 | 用户会看不见重点 | 先输出最关键的 3 个判断和动作 |

## 2. 边界场景处理

- 用户要确定结果：不写确定结论，改写成“基于已知材料的初步判断”。
- 用户材料不完整：不补编事实，只列待补字段。
- 用户要求强转化：保留顾问可说出口的表达，不使用压迫式话术。
- 用户给了多份材料：先做事实合并，再输出判断，不混在一起写。

## 3. FAQ

**问：材料很少时能不能直接生成？**  
能生成低置信版本，但必须标出缺什么，不写成终稿。

**问：用户只想要一句话，是否还要完整模板？**  
先给一句话判断，再附 3 条以内的依据和下一步动作。

**问：和其他陈庚 Skill 重叠怎么办？**  
先完成本 Skill 的核心交付，再给交接建议，不把多个角色混成一个答案。

**问：怎么判断输出合格？**  
看 4 点：是否回答原始任务，是否区分事实和判断，是否给出下一步动作，是否没有越过专业边界。

## FAQ 扩展：触发、重试和交接

| 问题 | 处理 |
|---|---|
| 用户只给了“帮我做一下”怎么办？ | 返回 `E002_CONTEXT_WEAK`，追问 `聊天记录`、任务场景和输出对象。 |
| 用户给了很多材料但没有目标怎么办？ | 先做材料归类，再追问希望得到 `沟通摘要` 还是其他结果。 |
| 输出里缺了关键模块怎么办？ | 按 `references/output-schema.md` 重写一次，不继续补丁式扩写。 |
| 用户要求确定结果怎么办？ | 改成条件判断和待确认项，保留边界提醒。 |
| 任务不属于本 Skill 怎么办？ | 说明原因，交接到更合适的陈庚 Skill。 |

## 常见错误对照

| 错误句式 | 问题 | 改法 |
|---|---|---|
| “我直接给你最终答案” | 没有做输入校验 | 先写输入校验和缺口 |
| “这个一定可以” | 写成确定承诺 | 改成“基于现有材料，倾向于……” |
| “建议长期坚持输出价值” | 信息密度低 | 改成今天、本周、下次要做的动作 |
| “这个问题很复杂” | 没有交付 | 拆成事实、判断、待确认项 |
| “所有渠道都可以做” | 没有优先级 | 给主渠道、备选渠道和放弃项 |
