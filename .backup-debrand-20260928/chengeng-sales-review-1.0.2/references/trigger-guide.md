# 触发指南

本文件回答：什么时候用 `陈庚-销售复盘`，怎么发起任务，什么时候交接到别的 Skill。

## 1. 适用触发

- 用户说“帮我做 / 诊断 / 生成 / 复盘 / 审查 / 整理”并且任务属于 `陈庚-销售复盘`。
- 用户提供了真实材料，而不是只有一句愿望。
- 用户要求输出能直接进入工作流，而不是泛泛解释概念。

## 2. 输入材料

- `聊天记录`：用户可直接粘贴，也可以用摘要。
- `面谈记录`：用户可直接粘贴，也可以用摘要。
- `方案讲解记录`：用户可直接粘贴，也可以用摘要。
- `跟进结果`：用户可直接粘贴，也可以用摘要。
- `顾问复盘备注`：用户可直接粘贴，也可以用摘要。

缺少关键输入时，不拒绝用户；先给可补字段，再给低置信初判。

## 3. 输出承诺

- `沟通摘要`：必须在输出里有明确小节或等价内容。
- `事实推断分离`：必须在输出里有明确小节或等价内容。
- `客户阶段判断`：必须在输出里有明确小节或等价内容。
- `销售卡点`：必须在输出里有明确小节或等价内容。
- `沟通表达诊断`：必须在输出里有明确小节或等价内容。
- `下一步动作`：必须在输出里有明确小节或等价内容。
- `可复用经验`：必须在输出里有明确小节或等价内容。

输出不能只给建议，必须给结构、依据、缺口和下一步动作。

## 4. 交接判断

- 定位不清：交给 `陈庚-PSP定位诊断` 或 `陈庚-八大人群`。
- 人设表达不清：交给 `陈庚-账号人设`。
- 内容生产任务：交给内容类 Skill。
- 销售沟通任务：交给销售教练类 Skill。
- 服务记录和后续维护：交给服务助理类 Skill。
- 已执行后的数据分析：交给复盘分析师类 Skill。

## 5. 三个调用样式

```text
使用 $chengeng-sales-review。我提供完整材料，请直接按默认模板输出。
```

```text
使用 $chengeng-sales-review。材料不完整，先判断缺什么，再给低置信版本。
```

```text
使用 $chengeng-sales-review。如果任务不适合这个 Skill，请说明原因并推荐交接。
```
