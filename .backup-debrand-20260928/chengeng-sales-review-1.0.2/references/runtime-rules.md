# 运行规则与质量门

本文件用于提升 `陈庚-销售复盘` 在复杂任务里的稳定性。平台不能运行脚本时，按同一规则人工自检。

## 1. 输入校验

| 字段 | 缺失处理 | 默认值 |
|---|---|---|
| 聊天记录 | 缺失时先追问；不影响初判时标为待确认 | 未提供 |
| 面谈记录 | 缺失时先追问；不影响初判时标为待确认 | 未提供 |
| 方案讲解记录 | 缺失时先追问；不影响初判时标为待确认 | 未提供 |
| 跟进结果 | 缺失时先追问；不影响初判时标为待确认 | 未提供 |
| 顾问复盘备注 | 缺失时先追问；不影响初判时标为待确认 | 未提供 |

最低要求：必须知道任务场景、目标对象、已有材料、输出给谁看。缺少其中任意一项时，不直接写终稿。

## 2. 状态码

| 代码 | 含义 | 处理 |
|---|---|---|
| `READY` | 信息足够 | 按默认模板输出 |
| `E001_INPUT_MISSING` | 缺关键字段 | 先问最多 5 个问题，或给低置信版本 |
| `E002_CONTEXT_WEAK` | 只有一句抽象要求 | 只做初判，不写完整终稿 |
| `E003_SCOPE_OUT` | 超出本 Skill 范围 | 说明原因，并交接到更合适的 Skill |
| `E004_FACT_CONFLICT` | 材料前后冲突 | 暂停终稿，列冲突点 |
| `E005_REVIEW_REQUIRED` | 涉及确定结果或外部专业判断 | 改成待确认表达，提醒用户核对来源 |

## 3. 默认输出模块

每次输出至少包含：

- `沟通摘要`
- `事实推断分离`
- `客户阶段判断`
- `销售卡点`
- `沟通表达诊断`
- `下一步动作`
- `可复用经验`
- `输入校验`
- `依据与缺口`
- `下一步动作`
- `边界提醒`

如果第一次输出缺少以上模块，按模板重写一次，不继续扩写。

## 4. 恢复规则

- 信息不足：输出缺口清单、低置信判断和最小追问。
- 材料冲突：停止终稿，列出冲突项，不替用户选择事实。
- 要求越界：说明不能写成确定结论，给出可替代表达。
- 输出过散：压回默认模块，优先交付用户最需要的 3 个动作。

## 5. 可选脚本

可运行 `scripts/quality_gate.py` 对任务材料做预检。脚本输出 `ready`、`needs_more_info` 或 `needs_review`，用于决定是否进入终稿。
