# 路由样例

## 1. 第一次使用

输入：

```text
第一次使用，不知道怎么开始。
```

预期：读取 `onboarding.md`，说明可以直接提交问题、材料、目标或卡点，并邀请用户说出最近要推进的事情。不展示 38 个 Skill。

## 2. 只有模糊感受

输入：

```text
我最近业务很乱，帮我看看。
```

预期：不要要求填写完整问卷，只问 1 个决定性问题：

> 你现在最想先处理的是“没有人来咨询”，还是“有人来问但推进不下去”？

用户回答后立即选择内容或销售方向的 1 个主 Skill。

## 3. 客户明确说贵

输入：

```text
这是客户聊天记录。对方说你们保险都差不多，你这个太贵了。
```

预期输出：

```markdown
## 当前判断

- 主 Skill：陈庚-异议处理
- 现在先处理：判断“贵”背后的真实异议，并准备下一轮回应。
- 判断依据：客户已经给出明确的价格比较和价值怀疑，不需要先做完整定位。

## 还缺什么

- 可以直接开始；如果聊天记录里有前文，一并沿用。

## 下一步

这一步交给「陈庚-异议处理」，直接沿用刚才的聊天记录。
```

## 4. 面谈录音转写

输入：

```text
这是昨天的面谈转写，帮我整理纪要，并看看怎么跟进。
```

预期：主 Skill 为 `陈庚-会议纪要`。先还原事实、需求和行动项；纪要出来后，再根据客户阶段判断客户筛选、方案呈现或销售复盘，不在第一步同时调用。

## 5. 想发朋友圈但没有选题

输入：

```text
今天想发一条朋友圈，但不知道发什么。
```

预期：主 Skill 为 `陈庚-朋友圈`。用户要的是一条可发布内容，不先改道到内容策略。朋友圈 Skill 内部再根据当天素材和目的追问。

## 6. PSP 已完成后问下一步

输入：

```text
刚做完 PSP。目标客户是杭州 35～45 岁的企业主家庭，主要问题是家庭资产和企业经营风险混在一起。下一步做什么？
```

预期：主 Skill 为 `陈庚-账号人设`，把已确认定位转成账号身份、信任资产和主页呈现。当前线上目录没有收费咨询产品 Skill，不输出这个本地名称。

## 7. 会议纪要完成后问下一步

输入：

```text
纪要已经整理完。客户需求明确，也同意下周再聊，但还没有进入具体方案。下一步呢？
```

预期输出：

```markdown
## 当前判断

- 主 Skill：陈庚-方案呈现
- 现在先处理：把已确认需求转成客户能理解的方案讲解结构。
- 判断依据：需求已经明确，客户也同意继续沟通；当前缺口是下一次会谈的方案表达，不是重新筛选客户。

## 还缺什么

- 纪要里的家庭情况、目标、预算和已有保障。

## 下一步

沿用会议纪要，交给「陈庚-方案呈现」。
```

## 8. 用户明确点名 Skill

输入：

```text
使用陈庚-养老金测算。这是我的年龄、社保缴费和退休目标。
```

预期：返回 `direct_skill`，直接进入 `陈庚-养老金测算`，不由总入口改成养老现金流测算或资料接入。

## 9. 体系说明

输入：

```text
我想完整理解定位、人设、内容、销售、服务、复盘这套体系。
```

预期：主 Skill 为 `陈庚-增长体系`。总入口只做交接，不在当前回答里复制完整理论。

## 10. 平台不能跨 Skill 调用

输入：任何已经完成路由的任务。

预期：不说“已经调用”。按 `handoff-contract.md` 输出目标 Skill 和完整交接卡，让用户直接继续。
