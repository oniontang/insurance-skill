## 本地有、线上没有

本地目录中的下列能力不作为当前路由目标：收费咨询产品、内容日历、直播内容、内容审查、养老现金流测算、教育金测算、理赔助理、转介绍、服务复盘、短视频复盘、直播复盘、资料接入、合规边界、输出质检、API 桥接等。

用户提出这些需求时，不要假装线上已有对应 Skill。可以：

1. 在现有 23 个 Skill 中有明确能力覆盖时，选择最接近且不越界的 1 个。
2. 没有合适覆盖时，直接说明“当前线上 Skill 暂无对应能力”，不要输出本地未发布名称。

## 维护规则

- 线上新增、删除、改名或升级 Skill 后，重新读取账号公开接口并更新本表。
- 路由只能使用本表 23 个子 Skill 的对外名称和 slug。
- 总入口 `growth-router` 不作为自己的子路由目标。
- 本地目录数量不能作为线上清单依据。
