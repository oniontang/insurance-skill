# 任务后导航

## 先读结果，不按固定链继续

任务完成后，提取：

- 上一轮使用的 Skill。
- 已经确认的结论。
- 尚未解决的问题。
- 新产生的材料。
- 用户现在想达到的结果。

然后只在 `skill-catalog.md` 的 23 个线上子 Skill 中选择当前 1 个主 Skill。用户已经明确下一步时，尊重用户目标。

## 常见导航

### 定位结果出来后

| 结果信号 | 当前主 Skill |
|---|---|
| PSP 还不成立，客群或问题过宽 | 继续PSP定位诊断 |
| 已明确目标客群，想判断八类人群特征 | 八大人群 |
| 已明确定位，要转成选题、语调和视觉 | 定位元素表 |
| 定位清楚，要塑造账号身份和信任 | 账号人设 |

### 人设与内容结果出来后

| 结果信号 | 当前主 Skill |
|---|---|
| 人设已经确定，要安排长期内容 | 内容策略 |
| 已有明确选题，要产出平台内容 | 对应的朋友圈、短视频、长视频、小红书或公众号长文 |
| 朋友圈、视频或文章带来私信，客户刚开始咨询 | 预咨询 |

### 咨询与销售结果出来后

| 结果信号 | 当前主 Skill |
|---|---|
| 预咨询完成，客户适合约正式咨询 | 轻咨询 |
| 预咨询后仍不确定是否值得推进 | 客户筛选 |
| 轻咨询确认了需求，需要讲方案 | 方案呈现 |
| 面谈中出现明确反对理由 | 异议处理 |
| 面谈结束，先要还原事实和行动项 | 会议纪要 |
| 已有纪要，客户阶段不清 | 客户筛选 |
| 已有纪要，需求清楚且要进入方案 | 方案呈现 |
| 已有纪要，过程卡住且原因不清 | 销售复盘 |
| 需要量化养老基础缺口 | 养老金测算 |

### 服务与复盘结果出来后

| 结果信号 | 当前主 Skill |
|---|---|
| 新增了稳定的客户事实和需求变化 | 客户画像 |
| 续保沟通后发现保障或需求变化 | 客户画像 |
| 销售复盘发现客群或问题不真实 | PSP定位诊断 |
| 销售复盘发现身份模糊、缺少信任证据 | 账号人设 |
| 销售复盘发现客户阶段判断错误 | 客户筛选 |
| 销售复盘发现异议没有被识别 | 异议处理 |

## 无法判断时

不要列出多个平行选项让用户自己选。只问一个会改变路由的问题：

- “这次你更需要还原事实，还是判断为什么没推进？”
- “客户现在已经答应进入方案，还是仍在犹豫要不要继续聊？”
- “你要先做养老金基础估算，还是已经有方案需要讲给客户听？”

用户回答后立即选择 1 个主 Skill。

## 线上能力边界

上一轮结果指向理赔、教育金测算、直播、转介绍、服务复盘、短视频复盘等未上线能力时，直接说明当前线上目录没有对应 Skill。不要沿用本地目录名称进行路由。
