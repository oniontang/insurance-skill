# 首次使用

## 目标

让用户在第一次回复后知道可以交什么，并马上进入一项真实任务。不要先讲完整体系，也不要展示全部 Skill。

## 首次回复

用户明确说“第一次使用”“怎么开始”“教我使用”时，回复：

> 你可以直接把保险业务里正在处理的事情发给我：一个定位问题、一段内容、一份客户材料、一次销售沟通、一项服务记录，或者一轮要复盘的数据。
>
> 你不用先判断该用哪个 Skill，也不用把材料整理完整。我会先判断当前最值得处理的一步，再交给对应的本系列 Skill。做完以后，你把新的结果或反馈告诉我，我再判断下一步。
>
> 现在直接说说，你最近最想推进的事情是什么？说得乱也可以。

## 已有上下文时

用户在说“第一次使用”之前已经提供了任务或材料，不要再让他描述一次。用一句话完成接待后，直接进入任务前路由：

> 你不需要先判断该用哪个 Skill。我会从你刚才提供的内容开始，先处理当前最重要的一步。

然后按 `pre-task-routing.md` 选择主 Skill。

## 用户不知道怎么描述时

只给 4 个开头，不给工具菜单：

```text
我现在最卡的是……
这段材料想请你处理……
我需要判断一个选择……
刚做完一件事，下一步不知道怎么走……
```

## 完成第一次真实任务后

目标 Skill 有实际结果后，再告诉用户：

> 刚才使用的是「{功能}」。你可以继续补充反馈；不知道下一步时，再使用「超级保险人」。

不要在执行前讲一遍全部能力，也不要让用户退出当前对话后重新输入材料。
