# JR/T 0197-2020《金融数据安全 数据安全分级指南》

> 中国人民银行发布，2020年9月23日实施

## 核心框架

### 1. 数据安全分级（5级）

| 级别 | 描述 | 典型数据 |
|------|------|---------|
| 5级 | 严重危害国家安全、公共利益 | 核心密钥素材、大规模个人金融信息原始数据 |
| 4级 | 危害国家安全、公共利益 | 大量C2/C3信息、交易数据集合 |
| 3级 | 损害公共利益、个人权益 | 个人金融信息、账户信息 |
| 2级 | 损害机构利益 | 内部经营数据 |
| 1级 | 无可见损害 | 公开信息 |

### 2. 与 JR/T 0171 的关系

JR/T 0197 是**数据分级框架**，JR/T 0171 是**个人金融信息保护**的行业规范。
两者互补：JR/T 0197 确定级别 → 应用相应的安全控制措施。

### 3. 结合 Fin-PIPL

见 SKILL.md 中"个人金融信息分类分级"检查项。检查项基于 JR/T 0197 的 5 级分级框架。
